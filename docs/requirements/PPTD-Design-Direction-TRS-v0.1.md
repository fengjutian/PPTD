> 状态：草案，待评审（2026-10-24；2026-10-25 修订：方向数量由 2–3 调整为 4，新增 `paper` / `instrument` 两个可渲染预设）

> 上游依据：[TRS V1.0](PPTD-TRS-v1.0.md) 4.2 AI 内容生成、4.3 内容与设计隔离、4.6 模板库与主题引擎、5.3 Design Model、6.3 Design Agent、10.1–10.4 测试要求

### 1.2 问题陈述

- **P-1 设计多样性不可用。** 即使模型写出不同的 `idea` 和 `rationale`，`resolveDeckConcept` 也会把非 `editorial` 的意图降级为编辑式并记一条 conflict。整册的骨架变化主要来自 12 个页面配方与配色，而不是视觉语言。
- **P-2 选择权缺失。** 用户在生成前只能选主题色板，看不到“两种不同骨架的封面 + 正文”再决定；方向错了只能整册重来。
- **P-3 预设不可见。** 选择器只能读描述，用户无法判断“纸墨”和“青花瓷韵”排出来差在哪里；同一批预设也无法作为回归基线。
- **P-4 品味问题不可诊断。** 字号过小、字体过多、色相过多、标题上方的小标签、非序列编号、连续三页同骨架，这些“像 AI 做的”问题不在任何确定性检查里，只能靠视觉评审给一个总分。
- **P-5 重复外观无记忆。** 连续做三个科技类主题，可能三套都是深底加等权卡片；用户反复手动改掉的同一个毛病，系统不会记住。

## 2. 目标

1. 在逐页设计前提供 4 个**真实可渲染**的设计方向，由用户选择或显式跳过。
2. 让“方向”成为可渲染、可记录、可复现的设计态事实，而不是提示词里的一段描述。
3. 让主题预设的差异可见、可验收、可回归。
4. 提供确定性的品味检查，把“像不像 AI 做的”变成可定位、可解释、**不阻断产出**的报告。
5. 在不联网、不上传正文的前提下积累本地设计记忆，减少重复外观。

## 3. 非目标

- 不引入 HTML/CSS 作为设计真源，不新增第二套几何或坐标体系。
- 不实现自由画布生成或任意坐标输出；几何仍由编译器与配方生成。
- 不替代视觉评审。确定性检查只覆盖可判定项，不判断“好不好看”。
- 不修改内容模型、内容审核流程、内容版本与内容哈希规则。
- 不承诺“多方向一定更好”；是否保留该环节以第 13 节的盲选验证为准。
- 不在本轮实现 PPTX 导入、OOXML 保真、字体库、3D 或布局编辑器扩展。

## 7. 功能需求

### FR-D1 方向提案

**目的**：在花费整册设计成本之前，让用户看到结构上真正不同的选项。

**触发**：内容已确认，且当前内容 revision 尚未产生方向记录。用户可在设置中关闭该环节；关闭后沿用现有单方向路径，不显示空步骤。

**输入**：已确认内容、SlideBrief、模板分析、主题方向；若启用设计记忆，附带最近项目的设计指纹摘要。

**输出**：4 个方向，每个方向包含：

- 概念预设、名称（不超过 12 字）、一句话立意（1–80 字）、适配理由；
- 字阶对比与图像策略；
- 2 页真实渲染预览：封面 + 一页有代表性的正文页。

四个方向分别使用 `editorial`（编辑式）、`documentary`（纪实全幅）、`paper`（纸本专栏）与 `instrument`（数据仪表）四个可渲染预设；它们必须覆盖全部四个，而不是只挑选其中几个。

**规则**：

1. 同一提案内的方向必须使用不同概念预设，不能是同一骨架换色。
2. 预览必须是产品真实渲染结果，不得使用示意图、模型描述或占位图。
3. 方向只包含设计态；不得包含正文、坐标、字号或装饰元素。
4. 预览不得写入文档、不得产生撤销项、不得改变任何 revision。
5. 生成失败、超时或取消时，回退现有单方向路径并明确提示，不阻断整册生成。

**验收**：AC-D1、AC-D2。

### FR-D2 方向选择、跳过与记录

- 用户选择后，所选方向作为整册设计方向进入逐页设计；不重新生成已确认内容。
- 提供“换一组”（同一次内容 revision 内最多 2 次）与“跳过”。
- “跳过”记为 `fallback`，同一内容 revision 不再重复询问；用户再次主动生成本轮设计时重新询问。
- 方向记录写入项目，重新打开后仍可查看；包含最终展示的提案集合、所选方向、选择方式、用户原话（可选，截断至 200 字）、内容 revision、时间、模型与提示词版本、重新生成次数。
- 记录不进入内容哈希，不改变内容版本；撤销整册设计应用时一并撤销。
- 内容在记录之后发生变化时，旧记录保留为历史，但不得被当作当前方向依据；应用时返回稳定错误（见第 10 节）。

**验收**：AC-D3、AC-D4。

### FR-D3 可渲染概念预设不少于 4 个

- 至少四个概念预设能完整渲染现有 12 个页面配方。
- 四个预设必须在表面策略、字阶对比、图像策略上两两可区分，而不是只换配色；`paper` 的窄栏版心与 `instrument` 的左侧栏/竖线属于表面策略差异，必须由渲染路径真实产生。
- 模型只能从可渲染集合中选择；不可渲染值必须被拒绝或降级并记录 conflict，不得静默接受。
- 预设新增必须同时提供渲染实现；合同里出现而渲染器画不出的值不得进入枚举。

**验收**：AC-D5。

### FR-D4 主题样张

- 每套内置主题预设提供 8 页样张：封面、章节、正文、指标、表格、图表、图片、结论。
- 样张由产品编译器生成，不以手写 HTML 截图代替。
- 样张用于：主题选择器预览、视觉回归基线、导出兼容样本、方向提案的 grounding。
- 样张缺失时选择器降级为文字描述，不得显示空白、假图或“生成中”假状态。
- 样张必须可由仓库内命令重建，并带生成时间、主题预设 ID、概念预设 ID、生成器版本。

**验收**：AC-D6。

### FR-D5 设计体检

- 检查项分两级：
  - **硬底线**：可读性（正文字号、标签字号、标题与正文字阶比）。
  - **软提示**：模板装饰、色彩与字体数量、跨页骨架重复、留白不足或过空。
- 每条问题包含：稳定 code、级别、`slideId`、`elementIds`、用户可读消息、度量值、可选建议。
- 只报告，不阻断生成与导出；导出报告汇总各级数量与 code。
- 检查必须确定性：同一文档、同一版本、同一设置下输出稳定顺序与相同结果。
- 至少覆盖：正文字号下限、标签字号下限、标题/正文字阶比、字体族数量、非中性色数量、标题上方小标签、非序列编号、emoji 装饰、单字变色、连续同骨架、留白比例。
- 像素级问题（模板底图里的装饰、图片内文字）不在确定性检查范围，交由视觉评审，并在报告中标注“未覆盖”。

**验收**：AC-D7、AC-D8。

### FR-D6 设计记忆（本地）

- 仅在本机保存最近 N 个项目的设计指纹：配色槽、字体对、概念预设、配方序列、页数；不保存正文、备注、图片或模型原始响应。
- 用户显式偏好按原话保存，并记录适用范围（例如“仅用于方案汇报类”）。
- 仅用于两件事：方向提案时避免与最近项目重复；主题预设推断时的偏置。**不得自动改变**用户已选主题或已应用设计。
- 用户可查看、单条删除、全部清空、关闭该能力。
- 关闭或清空后，后续提案不得再引用历史数据。

**验收**：AC-D9。

### FR-D7 视觉资产来源

- 每张进入项目的图片记录：来源 URL、获取时间、许可说明、内容哈希、核验状态（已核验 / 待核验 / 用户自定义）。
- 无来源或未核验的资产不得标记为“官方素材”，不得出现在“官方 logo 墙”一类断言里。
- 沿用 TRS 4.6 对传统色来源状态的既有约定；来源不明确的资源不得作为内置商业资产发布。
- 资产面板与导出报告显示核验状态；失败或缺失显示“未核验”，不得默认通过。

**验收**：AC-D10。

### FR-D8 导出回读校验

- 导出后独立读取生成的 `.pptx`，逐页比对：文本内容、图片数量、形状数量、表格与图表数量、页面顺序。
- 校验实现不得复用导出映射代码；对照源一侧来自文档快照，另一侧来自包内 XML。
- 不一致时导出报告标记 parity 失败，给出页码与对象类型；不删除已生成文件，不改变项目状态。
- 校验失败属于报告问题，不自动重试或静默修复。

**验收**：AC-D11。

### FR-D9 评审概念分

- 视觉评审增加“概念 / 立意”维度：能否用一句话说出这一页的 idea；换一个主题或客户名是否仍然成立。
- 概念分低于阈值时总分封顶，并在报告中说明封顶原因。
- 概念分不得覆盖确定性检查结论；两者在报告中分开呈现。
- 模型未返回概念分时按“未评分”处理，不得补造分数。

**验收**：AC-D12。

### FR-D10 数据页关系维度

- 指标页先判定关系：比例、变化、构成、对比、规模。
- 编译器据此选择表示方式；不得默认“三个大数字 + 条形图”。
- 当前渲染器不支持的表示必须报告 conflict，不得声称已渲染。
- 内容数值仍来自已审核内容块，设计侧不得改写数值。

**验收**：AC-D13。

### FR-D11 渲染器证据等级

- 每条视觉结论标注来源：PowerPoint、LibreOffice、画布、缩略图。
- 不同来源的结论分开呈现；低可信来源不得单独构成“通过”。
- 渲染器不可用时显示“未执行”，不得显示“通过”。

**验收**：AC-D14。

### FR-D12 提示词回归套件

- 维护固定主题集（不少于 6 个题材），记录模型、提示词版本、方向、评分与耗时。
- 用于模型或提示词变更前后的人工对比与决策，不进入 CI。
- 结果只作为评审材料，不作为“模型能力”的对外声明。

**验收**：AC-D15。

## 8. 约束

- **C-1 内容/设计隔离**：方向与体检不得修改标题、正文、数值、引用、备注、页面顺序；内容哈希保持不变。
- **C-2 revision**：预览与体检不改变任何 revision；选择方向与应用设计属于同一次设计事务，只产生一个撤销项。
- **C-3 单位**：阈值同时用 pt 与页宽比例表达，内部仍以 EMU 持久化；不得把像素当作持久单位。
- **C-4 可追溯**：方向记录、导出 parity、体检计数都可从项目或导出报告回看；不保存模型原始响应。
- **C-5 本地优先**：设计记忆仅本地；不得上传正文、图片或指纹。
- **C-6 不阻断**：视觉与品味问题不阻断生成或导出，[ADR 0015](../architecture/decisions/0015-visual-qa-failure-must-not-block-generation.md) 继续有效。
- **C-7 降级诚实**：任何未执行、未覆盖、超时的检查必须显示“未执行”，不得显示“通过”。

## 9. 非功能需求

| 类别     | 要求                                                                                                      |
| -------- | --------------------------------------------------------------------------------------------------------- |
| 性能     | 20 页文稿的方向阶段（1 次提案 + 4×2 页预览）额外耗时不超过整册设计的 60%；预览首帧（不含模型）小于 1.5 秒 |
| 成本     | 方向阶段最多设计 8 页（4 个方向 × 2 页），另加 1 次提案调用；不得等价于一次完整整册重跑                   |
| 取消     | 方向生成与预览可取消；取消后不写入任何状态，回到内容确认后的状态                                          |
| 离线     | 无网络时跳过方向；无视觉模型时只跑确定性体检                                                              |
| 可诊断   | 所有失败有稳定错误码、用户可读消息和可选诊断上下文                                                        |
| 可访问性 | 方向卡片可用键盘选择；缩略图有替代文本（方向名 + 立意）；焦点顺序与视觉顺序一致                           |
| 隐私     | 日志不记录正文、原始提示词或图片数据；设计记忆不含内容文本                                                |

## 10. 错误与降级

| 错误码                       | 场景                       | 行为                                           |
| ---------------------------- | -------------------------- | ---------------------------------------------- |
| `AI_DIRECTIONS_INVALID`      | 提案数量、预设或字段非法   | 回退单方向，提示“方向生成不可用”，保留已选主题 |
| `AI_DIRECTIONS_TIMEOUT`      | 模型超时                   | 同上；不自动重试超过一次                       |
| `DESIGN_DIRECTION_CANCELLED` | 用户取消                   | 不写入，回到内容确认后状态                     |
| `DESIGN_DIRECTION_STALE`     | 内容 revision 或指纹已变化 | 丢弃提案，不应用，提示重新生成                 |
| `TASTE_LINT_UNAVAILABLE`     | 检查执行异常               | 报告标记“未执行”，不显示通过                   |
| `EXPORT_PARITY_MISMATCH`     | 回读与快照不一致           | 保留文件，报告逐页差异，不改变项目             |

## 11. 验收场景

- **AC-D1（方向可见）**：给定 3 个题材与同一份已确认内容，触发方向提案，得到 4 个方向；每个方向有 2 张真实渲染预览，且不同方向的封面骨架在结构上不同（元素类型序列不同）。
- **AC-D2（零副作用）**：生成与预览前后，文档的 `contentRevision`、`designRevision`、`documentRevision`、内容哈希与撤销栈均不变。
- **AC-D3（选择生效）**：选择方向 B 后整册设计使用 B 的概念预设；方向记录可在重新打开项目后查看，并包含所选 ID 与内容 revision。
- **AC-D4（跳过与过期）**：跳过后再生成不重复询问；记录后修改内容，旧记录仍可查看但不能作为当前依据，应用时返回 `DESIGN_DIRECTION_STALE`。
- **AC-D5（预设合法）**：每个可渲染预设都能生成 20 页；因素材缺失产生的降级必须记录 conflict，不得静默；未知预设被拒绝并记录 conflict，不静默回退。
- **AC-D6（样张可用）**：11 套预设各有 8 页样张；重建命令输出与入库清单一致；选择器无样张时显示文字降级。
- **AC-D7（硬底线）**：构造 11pt 正文、8pt 标签、标题/正文 2.0 倍的文档，体检分别报出对应 code；同一文档重复执行结果一致。
- **AC-D8（软提示与不阻断）**：构造标题上方小标签、非序列 `01/02/03`、三页同骨架，体检报软提示；生成与导出仍成功，导出报告记录数量。
- **AC-D9（本地记忆）**：清空设计记忆后，方向提案不再引用历史；导出与项目文件不包含记忆内容。
- **AC-D10（资产来源）**：无来源图片显示“未核验”；标记已核验需要来源 URL、许可与哈希三者齐全。
- **AC-D11（回读独立）**：人为从导出包删除一段文本后，回读校验报出该页文本缺失；正常导出无 parity failure。
- **AC-D12（概念分）**：概念分低于阈值时总分被压到封顶值，报告给出原因；未返回概念分时显示“未评分”。
- **AC-D13（数据关系）**：给一组表示“变化”的指标，生成结果不得只用大数字 + 条形图；不支持的表示报 conflict。
- **AC-D14（证据等级）**：LibreOffice 单页渲染结论不得被展示为整套通过；PowerPoint 与画布结论分开列出。
- **AC-D15（回归套件）**：固定 6 个题材可重复执行并产出同一结构的记录文件；不纳入 CI。

## 12. 兼容与迁移

- 文档 Schema 从 19 升至 20：只新增可选字段 `designDirections`，迁移为恒等迁移并附固定样例；旧项目打开后行为不变。
- 没有方向记录的项目继续走现有单方向路径，不显示空步骤。
- 旧导出报告缺少 parity 与体检字段时按“未执行”展示，不补造数据。
- 视觉评审合同新增概念分为可选字段；旧模型响应不要求该字段。

## 13. 验证计划（不阻断交付）

方向环节是否保留，以一次小规模盲选验证为准：

1. 选 3 个题材（人文 / 科技 / 政务），各用风格差异最大的 2 套主题预设。
2. 每套只渲染 2 页（封面 + 典型正文），走现有编译器，不改 Schema。
3. 5–8 名目标用户盲选并说明理由。
4. 同时用设计体检草案检查落选版本，观察规则能否提前指出问题。

判据：多数参与者能说出明确偏好且理由指向**结构**而非配色，才继续投入完整方向选择 UI；否则优先改配方与字阶，而不是加流程。

## 14. 未决问题

1. 已决（2026-10-25）：默认 4 个，首次全部展示；四个方向分别对应四个可渲染预设，“换一组”换的是同一组骨架的新提案，而不是把第四个方向藏到下一轮。
2. 方向预览的 2 页由模型逐页设计，还是由编译器按概念直接生成？前者真实但更贵，后者便宜但代表性弱。
3. 体检阈值是否按页面角色区分（封面允许更小的标签与说明文字）？
4. 设计记忆的保留条数、去重窗口与“最近项目”的时间范围。
5. 是否允许用户把某个方向收藏为下次起点，以及该收藏是否属于设计记忆。
