## 1. 背景

TRS 4.4.4 要求编辑器参考 Microsoft PowerPoint 的操作模型，采用“标签页 + 命令分组”的功能区，同时明确禁止照搬品牌视觉或放置无响应的空按钮。当前“开始”标签已经接入剪贴板、页面、文本格式、查找和选择能力，但视觉上仍是一排没有分组标题的图标：字符格式和段落格式混在同一个两行控件里，格式刷藏在段落行末尾，绘图和编辑没有独立组，PowerPoint 用户找不到熟悉的位置。

本任务以 PowerPoint 365 “开始”选项卡为对照基线，先定义逐组差异和分期边界，再交付第一阶段。对照截图中的 OfficePLUS、加载项和 PDF 工具箱属于第三方或生态入口，不是 PPTD 当前产品范围，不复制。

## 2. 目标

1. “开始”标签按 PowerPoint 的高频分组组织为：剪贴板、幻灯片、字体、段落、绘图、编辑。
2. 每组只展示当前文档模型、命令层、画布和导出器共同支持的命令。
3. 撤销/重做移到标签行右侧的快速访问位置，和 PowerPoint 的 QAT（快速访问工具栏）习惯一致。
4. 字体与段落拆成两个有标题的组，格式刷回到剪贴板。
5. 为已有多选形状补齐一次事务的批量填充/轮廓命令，不通过循环执行多条命令伪造批量操作。
6. 查找和替换是两个入口；替换入口打开查找栏并直接聚焦“替换为”。新增 `Ctrl+H`。
7. 第一阶段不新增没有模型支撑的版式选择、分节、字符间距、文本突出显示、分栏、SmartArt、文字方向、透明度或快速样式按钮；第二阶段先接入已有模型和导出路径的字符间距，再按“重建构图、保留内容和手工对象”的语义接入版式选择。

## 4. 分期范围

### 4.1 第一阶段：包含

- 新增可复用的功能区组容器：组标题、组间分隔线、紧凑命令按钮。
- “开始”标签重排为六组，并保留现有命令的真实禁用状态。
- 撤销/重做改为标签行右侧的快速访问按钮，在所有标签下可用。
- 剪贴板组：粘贴、剪切、复制、格式刷、删除对象。
- 幻灯片组：新建、复制、重置版式、删除、上移/下移；每次操作仍是一个撤销项。
- 字体组：字体、字号、增减字号、粗体、斜体、下划线、删除线、文字颜色、清除格式。
- 段落组：水平对齐、垂直对齐、行距、项目符号、编号、减少/增加缩进。
- 绘图组：形状菜单、形状填充、形状轮廓、跳转到“排列”标签。
- 编辑组：查找、替换、选择菜单（全选本页、选择窗格、取消选择）。
- 新增 `set-shape-styles` 批量设计命令；同一批形状的填充/轮廓修改是一个事务。
- 查找栏支持初始焦点 `find` / `replace`；新增 `Ctrl+H` 打开并聚焦替换。
- 窄窗口下自动压缩按钮与组间距，导出按钮和快速访问不消失；1080px 最小窗口仍可完整显示六组。

### 4.2 第一阶段：不包含

- 版式选择器：第一阶段没有安全的“换版式”命令，直接改 `layoutId` 不会让画面跟着变；第二阶段补齐重建构图和保留对象的语义后再开放。
- 分节：文档模型没有节，页面面板也没有节级顺序和折叠状态。
- 文本突出显示：没有 `TextElementStyle` 字段，也没有画布和导出语义。
- 分栏、SmartArt、文字方向：没有文档模型、画布和导出器三者共同支持。
- 形状透明度、快速样式库、阴影效果面板：留到视觉词汇任务，避免在功能区硬编码主题色。
- OfficePLUS、加载项、PDF 工具箱：产品范围外。
- 系统剪贴板、截图、连接线：分别受 Tauri 权限、图片管线和连接点模型约束。

### 4.3 第二阶段：字符间距

第二阶段先做“已有完整数据链路、只缺入口”的能力，不把新模型和视觉词汇混在一起：

- 字体组在粗体/斜体/下划线/删除线之后增加字符间距预设：很紧 -1.5pt、紧密 -1pt、常规 0、稀疏 1pt、很松 1.5pt、更松 3pt；导入或主题带来的其他值显示为对应的 `n pt`。
- 属性面板“文字外观”增加“字距”数值输入，步进 0.1pt，范围 -2–20pt；功能区负责快速预设，面板负责精确值。
- PPTX 导入读取 `a:rPr` / `a:defRPr` 的 `spc` 属性（1/100 pt），换算为 `letterSpacingPt`；导出继续写回原生 `spc`，文本保持可编辑。
- 字符间距是设计态字段，不进入内容哈希；一次修改仍是一个设计事务和一个撤销项。
- 当前文本仍是单一字符串，间距作用于整个文本框。同一文本框内多个 run 使用不同 `spc` 时，沿用既有字符样式扁平化规则，只保留最后一个显式 run 的值；逐 run 间距不在本阶段扩展片段模型。
- 不修改 Schema：`letterSpacingPt` 已存在，本阶段不新增默认值或迁移。

### 4.4 第二阶段：版式选择

- 幻灯片组在存在至少一个可安全应用的替代版式时显示“版式”菜单；只有当前版式或全部不兼容时不显示空入口。
- 新增设计命令 `apply-slide-layout`。命令先解析目标版式并校验能力，再复用 `relayout-slide` 的生成链路重建单页构图；已审核标题、正文、内容块、备注、内容版本和页面语义顺序保持不变。
- 目标版式的能力决定构图族：`free` 版式按名称成为封面或章节页；`columns >= 2` 成为双栏；其余作为普通正文页。双栏只接受至少两条纯文本要点，或本身自带两栏语义的对比块。
- 换版式只替换生成构图；用户手工对象、锁定对象、内容图片和手工备注保留，分组关系按既有重排规则清除。目标版式的稳定 `id` 和背景写入页面，导出时继续成为该页的母版依据。
- 不兼容情况必须在菜单中说明原因而不是静默降级：缺少占位信息、无标题/正文占位、封面版式会隐藏正文、双栏装不下单条要点或含整行/引用内容，以及目标版式不存在。
- 版式只持久化名称、背景和能力摘要，不保存原始占位符几何。换版式会按目标能力重建构图，不会伪装成完整复刻源模板的占位符位置；这一限制在界面说明和领域模型中明确记录。

## 6. 技术设计

### 6.1 组件边界

- `src/features/editor/RibbonGroup.tsx`：组容器和紧凑按钮。只负责排版与可访问名称，不持有文档状态。
- `src/features/editor/FormatPainterTool.tsx`：从 `TextFormatToolbar` 中抽出的剪贴板格式刷入口，复用 `useFormatPainterStore`。
- `src/features/editor/DrawingRibbonTools.tsx`：形状菜单、填充/轮廓颜色和“排列”跳转。只对 `shape` 类型且未锁定的选择写命令。
- `src/features/editor/SelectionMenu.tsx`：全选、选择窗格、取消选择的弹出菜单。
- `src/features/editor/TextFormatToolbar.tsx`：新增 `section: "all" | "font" | "paragraph"`。`all` 保持旧测试和调用方行为；`font` / `paragraph` 各自排成两行紧凑布局。字体段包含字符间距预设，混合选择显示“多值”。
- `src/app/EditorRibbon.tsx`：负责把命令和当前选择接到上述组件，不把业务规则写进 JSX。

### 6.2 批量形状样式命令

```ts
{
  type: "set-shape-styles";
  slideId: SlideId;
  elementIds: ElementId[];
  style: Partial<ShapeElementStyle>;
}
```

- 仅处理同时满足“id 命中、类型为 shape、未锁定”的对象。
- 一个可编辑目标都没有时返回 `ELEMENT_NOT_SHAPE`，不产生空撤销项。
- 与单对象 `set-shape-style` 共用 `assertShapeStyle`，并保留“设置纯色填充时删除旧渐变”的规则。
- 影响域为 `design`；一个命令一个撤销项；内容 revision、内容哈希和审核状态不变。
- UI 以最后选中的形状为显示值；多选值不一致时在标题里说明“修改会统一”。

### 6.3 功能区布局

- 顶部行高从 88px 调整为 96px：29px 标签行 + 48px 命令体 + 组标题与间距。
- 组体使用 48px 高；字体/段落组内部可以两行 22px 紧凑控件，但组体总高度不变。
- 撤销/重做使用标签行右侧的 24px 快速访问按钮，不进入“开始”组。
- 窄窗口下 `.home-tools` 使用 `min-width: 0` 并依靠 1400px / 1200px 两级媒体查询压缩按钮、字体选择器和组间距；导出按钮保持在右侧，不使用会裁切弹出菜单的横向滚动容器。
- 组标题使用 `aria-label` 对应的可见文本，不依赖颜色表达状态。

### 6.4 查找与替换

- `FindReplaceBar` 增加 `initialFocus?: "find" | "replace"`，用 ref 在打开时聚焦对应输入框。
- `useAppRuntime` 增加 `findFocus` 和 `openFindReplace(mode)`；关闭仍复用 `setFindOpen(false)`。
- `Ctrl+F` 聚焦查找；`Ctrl+H` 聚焦替换；输入框内不拦截快捷键的现有规则不变。

### 6.5 字符间距

- 字体组使用原生 `<select>`，选项值直接是 point 数；没有选中文本或全部锁定文本时禁用，不产生空事务。
- 属性面板复用 `NumberField`，把 `letterSpacingPt` 限制在 -2–20；清空格式仍回退到主题令牌。
- Rust 导入器在 `RunStyle` 和 `ImportedTextStyle` 中增加 `letter_spacing_pt`，从 `spc` 的百分之一 pt 换算并夹取到模型范围；`defRPr` 继承路径与 run 覆盖路径都走同一个解析函数。
- TypeScript 映射保留显式 `0`，不能把“常规”误判为“没有设置”；Schema 已有字段，不新增迁移。

### 6.6 版式选择命令

```ts
{
  type: "apply-slide-layout";
  slideId: SlideId;
  layoutId: string;
}
```

- `slideLayoutOptions(document, slide)` 为功能区提供版式、当前项和不可用原因；`slideLayoutApplicationIssue` 同时被命令层复用，UI 禁用不是唯一防线。
- 目标不存在返回 `LAYOUT_NOT_FOUND`；目标与页面能力冲突返回 `LAYOUT_INCOMPATIBLE`，不产生空撤销项。
- 命令影响域为 `design`。`relayoutSlide` 增加可选 `targetLayout`，复用既有内容映射、图表/表格块 id 重映射和用户对象保留逻辑；成功后直接写目标 `layoutId`，不向 `layouts` 追加同名副本。
- 目标背景成为页面背景；若目标背景与旧页面明暗不同，标题、正文和强调色先按背景亮度解析可读墨色。目标背景图片从未持久化，因此换到其他版式时不沿用旧版式画面。
- 自由版式只生成标题/可选正文区域；双栏版式把安全正文框拆成左右两个区域，并在纯文本页强制 `composition: "columns"`；普通正文版式保留一个正文区域。统一由 `apply-ai-designed-draft` 生成可编辑元素。
- 现有 `relayout-slide` 继续表示“按当前版式重排”，保留当前版式背景画面；`apply-slide-layout` 表示“换到目标版式并重排”。

## 7. 验收

- **AC-1** 在 1440px 宽度下，“开始”显示剪贴板、幻灯片、字体、段落、绘图、编辑六组；标签行与组标题不重叠。
- **AC-2** 撤销/重做在所有标签可见；无可撤销/重做时禁用；执行后状态同步。
- **AC-3** 复制对象后删除来源仍可粘贴；格式刷单击一次、双击锁定、Esc 取消的行为与改造前一致。
- **AC-4** 新建、复制、换版式、重置、删除、上移、下移各只形成一个撤销项；只有一页时删除禁用；首尾页的移动方向按钮禁用；没有可应用替代版式时不显示版式入口。
- **AC-5** 字体/段落控件与属性面板同步；多选批量修改一次撤销回退；混合值仍显示虚线或未按下态。
- **AC-6** 选中两个不同颜色的形状，改填充后两者统一为一个新颜色；一次撤销全部恢复；锁定形状不被修改。
- **AC-7** 全选只包含当前页可见且未锁定的对象；取消选择后属性面板回到页面状态；选择窗格按钮状态与左侧面板一致。
- **AC-8** 点击“替换”后“替换为”输入框获得焦点；`Ctrl+H` 同样；`Ctrl+F` 仍聚焦查找。
- **AC-9** 锁定对象在批量样式、删除、格式命令中保持不变或被跳过，状态栏给出可理解结果。
- **AC-10** 页面中没有分节、突出显示、分栏、SmartArt、文字方向、透明度或快速样式按钮；字符间距和版式选择通过已有模型提供真实入口。
- **AC-11** 批量形状样式后 `content` revision 与 `contentHash` 不变，`design`/`document` revision 各 +1。
- **AC-12** 选中文本设置字符间距 1.5pt 后，画布和导出结果一致（`spc="150"`），一次撤销恢复；导入 `spc="80"` 的文本显示 0.8pt；内容哈希和审核状态不变。
- **AC-13** 选择双栏版式后，页面生成左右两栏构图、背景切换为目标版式、`layoutId` 指向目标且 `layouts` 不新增副本；已审核内容 JSON 和手工对象不变；一次撤销恢复原构图；不兼容版式显示原因且命令返回 `LAYOUT_INCOMPATIBLE`。

## 10. 已知限制

- 最小窗口宽度按 Tauri 配置为 1080px；在该宽度下六组和导出入口仍能放下，但按钮标题会压缩到约 8px。低于 1080px 不受支持，也没有实现 PowerPoint 的“组折叠为菜单”。
- 字体/段落组仍是紧凑图标，没有实现 PowerPoint 的完整下拉画廊。
- 字符间距作用于整个文本框；同一文本框内多个 run 使用不同 `spc` 时，导入沿用既有字符样式扁平化规则，只保留最后一个显式 run 的值。功能区只提供常用预设，精确值在属性面板输入，没有“更多间距”对话框。
- 多选形状批量样式只覆盖填充和轮廓；线条、图片、图标、表格和图表有各自命令，不能被绘图组误改。
- 版式只持久化名称、背景和能力摘要，没有原始占位符几何和版式画面。换版式按能力重建构图并使用目标背景，不能保证与源模板同位置、同装饰；目标版式若依赖未保存的背景图，换入后只保留其纯色背景，缺少纯色时沿用当前页背景色。
- 换版式会清除用户分组，与既有“重排版式”一致；分组内对象本身仍保留。
- 分节仍是“开始”功能区与 PowerPoint 的主要结构差异；版式选择器已不再缺失。
