| 项目     | 内容                                                         |
| -------- | ------------------------------------------------------------ |
| 状态     | 第一阶段已实现                                               |
| 优先级   | P0                                                           |
| 里程碑   | V0.2 专业编辑功能区                                          |
| 依赖     | TASK-EDIT-001、TASK-EDIT-002、TASK-EDIT-003、TASK-EDIT-004   |
| 需求依据 | TRS 4.4.4“专业编辑功能与功能区”、“开始”功能区                |

## 1. 背景

TRS 4.4.4 要求编辑器参考 Microsoft PowerPoint 的操作模型，采用“标签页 + 命令分组”的功能区，同时明确禁止照搬品牌视觉或放置无响应的空按钮。当前“开始”标签已经接入剪贴板、页面、文本格式、查找和选择能力，但视觉上仍是一排没有分组标题的图标：字符格式和段落格式混在同一个两行控件里，格式刷藏在段落行末尾，绘图和编辑没有独立组，PowerPoint 用户找不到熟悉的位置。

本任务以 PowerPoint 365 “开始”选项卡为对照基线，先定义逐组差异和分期边界，再交付第一阶段。对照截图中的 OfficePLUS、加载项和 PDF 工具箱属于第三方或生态入口，不是 PPTD 当前产品范围，不复制。

## 2. 目标

1. “开始”标签按 PowerPoint 的高频分组组织为：剪贴板、幻灯片、字体、段落、绘图、编辑。
2. 每组只展示当前文档模型、命令层、画布和导出器共同支持的命令。
3. 撤销/重做移到标签行右侧的快速访问位置，和 PowerPoint 的 QAT（快速访问工具栏）习惯一致。
4. 字体与段落拆成两个有标题的组，格式刷回到剪贴板。
5. 为已有多选形状补齐一次事务的批量填充/轮廓命令，不通过循环执行多条命令伪造批量操作。
6. 查找和替换是两个入口；替换入口打开查找栏并直接聚焦“替换为”。新增 `Ctrl+H`。
7. 本阶段不新增没有模型支撑的版式选择、分节、字符间距、文本突出显示、分栏、SmartArt、文字方向、透明度或快速样式按钮。

## 4. 第一阶段范围

### 4.1 包含

- 新增可复用的功能区组容器：组标题、组间分隔线、紧凑命令按钮。
- “开始”标签重排为六组，并保留现有命令的真实禁用状态。
- 撤销/重做改为标签行右侧的快速访问按钮，在所有标签下可用。
- 剪贴板组：粘贴、剪切、复制、格式刷、删除对象。
- 幻灯片组：新建、复制、重置版式、删除、上移/下移；每次操作仍是一个撤销项。
- 字体组：字体、字号、增减字号、粗体、斜体、下划线、删除线、文字颜色、清除格式。
- 段落组：水平对齐、垂直对齐、行距、项目符号、编号、减少/增加缩进。
- 绘图组：形状菜单、形状填充、形状轮廓、跳转到“排列”标签。
- 编辑组：查找、替换、选择菜单（全选本页、选择窗格、取消选择）。
- 新增 `set-shape-styles` 批量设计命令；同一批形状的填充/轮廓修改是一个事务。
- 查找栏支持初始焦点 `find` / `replace`；新增 `Ctrl+H` 打开并聚焦替换。
- 窄窗口下“开始”命令区允许横向滚动，导出按钮和快速访问不消失。

### 4.2 不包含

- 版式选择器和分节：直接改 `layoutId` 不会让画面跟着变，必须先定义“换版式时哪些对象保留”的命令语义。
- 字符间距、文本突出显示：前者需要明确 pt 输入和 PPTX 字符间距映射，后者没有 `TextElementStyle` 字段。
- 分栏、SmartArt、文字方向：没有文档模型、画布和导出器三者共同支持。
- 形状透明度、快速样式库、阴影效果面板：留到视觉词汇任务，避免在功能区硬编码主题色。
- OfficePLUS、加载项、PDF 工具箱：产品范围外。
- 系统剪贴板、截图、连接线：分别受 Tauri 权限、图片管线和连接点模型约束。

## 6. 技术设计

### 6.1 组件边界

- `src/features/editor/RibbonGroup.tsx`：组容器和紧凑按钮。只负责排版与可访问名称，不持有文档状态。
- `src/features/editor/FormatPainterTool.tsx`：从 `TextFormatToolbar` 中抽出的剪贴板格式刷入口，复用 `useFormatPainterStore`。
- `src/features/editor/DrawingRibbonTools.tsx`：形状菜单、填充/轮廓颜色和“排列”跳转。只对 `shape` 类型且未锁定的选择写命令。
- `src/features/editor/SelectionMenu.tsx`：全选、选择窗格、取消选择的弹出菜单。
- `src/features/editor/TextFormatToolbar.tsx`：新增 `section: "all" | "font" | "paragraph"`。`all` 保持旧测试和调用方行为；`font` / `paragraph` 各自排成两行紧凑布局。
- `src/app/EditorRibbon.tsx`：负责把命令和当前选择接到上述组件，不把业务规则写进 JSX。

### 6.2 批量形状样式命令

```ts
{
  type: "set-shape-styles";
  slideId: SlideId;
  elementIds: ElementId[];
  style: Partial<ShapeElementStyle>;
}
```

- 仅处理同时满足“id 命中、类型为 shape、未锁定”的对象。
- 一个可编辑目标都没有时返回 `ELEMENT_NOT_SHAPE`，不产生空撤销项。
- 与单对象 `set-shape-style` 共用 `assertShapeStyle`，并保留“设置纯色填充时删除旧渐变”的规则。
- 影响域为 `design`；一个命令一个撤销项；内容 revision、内容哈希和审核状态不变。
- UI 以最后选中的形状为显示值；多选值不一致时在标题里说明“修改会统一”。

### 6.3 功能区布局

- 顶部行高从 88px 调整为 96px：29px 标签行 + 48px 命令体 + 组标题与间距。
- 组体使用 48px 高；字体/段落组内部可以两行 22px 紧凑控件，但组体总高度不变。
- 撤销/重做使用标签行右侧的 24px 快速访问按钮，不进入“开始”组。
- 窄窗口下 `.home-tools` 使用 `min-width: 0; overflow-x: auto`，导出按钮保持在右侧。
- 组标题使用 `aria-label` 对应的可见文本，不依赖颜色表达状态。

### 6.4 查找与替换

- `FindReplaceBar` 增加 `initialFocus?: "find" | "replace"`，用 ref 在打开时聚焦对应输入框。
- `useAppRuntime` 增加 `findFocus` 和 `openFindReplace(mode)`；关闭仍复用 `setFindOpen(false)`。
- `Ctrl+F` 聚焦查找；`Ctrl+H` 聚焦替换；输入框内不拦截快捷键的现有规则不变。

## 7. 验收

- **AC-1** 在 1440px 宽度下，“开始”显示剪贴板、幻灯片、字体、段落、绘图、编辑六组；标签行与组标题不重叠。
- **AC-2** 撤销/重做在所有标签可见；无可撤销/重做时禁用；执行后状态同步。
- **AC-3** 复制对象后删除来源仍可粘贴；格式刷单击一次、双击锁定、Esc 取消的行为与改造前一致。
- **AC-4** 新建、复制、重置、删除、上移、下移各只形成一个撤销项；只有一页时删除禁用；首尾页的移动方向按钮禁用。
- **AC-5** 字体/段落控件与属性面板同步；多选批量修改一次撤销回退；混合值仍显示虚线或未按下态。
- **AC-6** 选中两个不同颜色的形状，改填充后两者统一为一个新颜色；一次撤销全部恢复；锁定形状不被修改。
- **AC-7** 全选只包含当前页可见且未锁定的对象；取消选择后属性面板回到页面状态；选择窗格按钮状态与左侧面板一致。
- **AC-8** 点击“替换”后“替换为”输入框获得焦点；`Ctrl+H` 同样；`Ctrl+F` 仍聚焦查找。
- **AC-9** 锁定对象在批量样式、删除、格式命令中保持不变或被跳过，状态栏给出可理解结果。
- **AC-10** 页面中没有版式选择、分节、字符间距、突出显示、分栏、SmartArt、透明度或快速样式按钮。
- **AC-11** 批量形状样式后 `content` revision 与 `contentHash` 不变，`design`/`document` revision 各 +1。

## 9. 实现记录

- 2026-10-26：完成第一阶段。新增功能区组容器、剪贴板/绘图/选择组件和批量形状样式命令；拆分字体与段落；撤销/重做移到快速访问；查找替换支持初始焦点和 `Ctrl+H`。
- 保留“删除对象”入口在剪贴板组；PowerPoint 将该操作主要放在键盘 Delete，本应用保留可见入口以避免功能回退。
- “版式”和“分节”未实现：当前 `relayout-slide` 会重新生成页面构图，并可能用生成出的版式替换 `layoutId`，不能伪装成 PowerPoint 的“换版式”。后续任务必须先定义保留对象和内容映射规则。
- 形状透明度、快速样式和阴影效果未实现；功能区不显示这些按钮。

## 10. 已知限制

- 窄于约 1280px 时，“开始”命令区会横向滚动；这与 TRS 允许的“组折叠为菜单”不同，是当前阶段的可用性降级，后续应把低优先级组折叠为菜单。
- 字体/段落组仍是紧凑图标，没有实现 PowerPoint 的完整下拉画廊。
- 多选形状批量样式只覆盖填充和轮廓；线条、图片、图标、表格和图表有各自命令，不能被绘图组误改。
- 版式选择器缺失仍是“开始”功能区与 PowerPoint 的主要结构差异。
