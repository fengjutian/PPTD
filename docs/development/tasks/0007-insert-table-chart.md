## 1. 背景

TRS 要求“插入”功能区提供原生可编辑表格和基础图表。此前表格和图表只能由 AI 设计阶段生成，手工插入没有入口；用户想加一张简单对照表或三项指标图，只能重新生成整页。

表格和图表都不是自包含对象：表格读取 `table-data` 内容块，图表读取 `metric` 内容块。手工插入必须同时创建内容和元素，否则导出的对象没有数据。

## 2. 目标

用户可以在“插入”功能区选择表格尺寸或图表类型，插入一个带占位数据、可立即在属性面板编辑、导出为原生表格/图表的对象；插入是一个可撤销的事务，并如实更新内容版本和审核状态。

## 3. 范围

### 3.1 包含

- `add-table` 命令：2–8 列、1–30 数据行，生成表头与空白单元格。
- `add-chart` 命令：柱状/条形/折线/饼图，生成 3 项示例指标。
- 插入表格对话框（列数、数据行数、预览）。
- 插入图表对话框（四种类型）。
- 插入后选中新对象，属性面板可编辑单元格或指标。
- 导出仍为原生表格/图表。

### 3.2 不包含

- 插入后增加/删除行列或增删图表序列（需要内容块结构迁移）。
- 从 CSV/剪贴板粘贴表格。
- SmartArt、组合图表、双轴图。
- 自动避让已有对象；新对象居中放置，可能与现有内容重叠。

## 4. 设计

### 4.1 命令

```ts
{
  type: "add-table";
  slideId;
  columns: number;
  rows: number;
}
{
  type: "add-chart";
  slideId;
  kind: ChartKind;
}
```

- 表格：创建 `table-data` 块（表头 `列 1…列 n`，空白行）并追加 `table` 元素；元素只持有 `contentBlockId`。
- 图表：创建 3 个 `metric` 块（项目 A/B/C，值 10/20/30）并追加 `chart` 元素；元素持有 `contentBlockIds`。
- 两者都按页面 62% 宽居中放置，归属 `user`、未锁定。
- 域是 `both`：新增内容块是内容变更，新增元素是设计变更；已确认页会被标记为 `changed`。
- 一次命令一个撤销项；store 选中新元素。

### 4.2 为什么用占位内容

- 空表格或空图表无法通过导出校验（表格要求表头/行，图表要求可解析指标）。
- 占位值让对象一插入就可见、可编辑，也明确告诉用户这些是要替换的示例数据。
- 占位数据是内容，会进入内容版本；这比“看起来有表格但导出为空”诚实。

### 4.3 UI

- 表格对话框限制 2–8 列、1–30 行，带网格预览和“含表头”提示。
- 图表对话框只选类型，固定三项示例指标；类型可在属性面板再次修改。
- 属性面板复用既有 `TableDataFields` / `MetricFields`，编辑单元格或指标会标记本页待确认。

## 5. 验收

- **AC-1** 插入 3 列 2 行表格，页面出现 3×3（含表头）原生表格，表头为“列 1…列 3”。
- **AC-2** 插入图表后出现 3 项可编辑指标，画布和导出都能看到 10/20/30。
- **AC-3** 插入是一次撤销；撤销后内容块和元素一起消失。
- **AC-4** 已确认页插入后变为 `changed`，内容版本递增。
- **AC-5** 表格列数 1/9、行数 0/31 被拒绝，文档不变。
- **AC-6** 导出的 PPTX 含 `<a:tbl>` 和原生 chart part，报告计数为 1/1。
- **AC-7** 插入后在属性面板改单元格/指标，画布和导出同步。

## 7. 已知边界

- 插入后不能调整表格行列数或增删图表指标；需要删除重插，后续另立内容迁移任务。
- 新对象居中放置，不与现有对象避让，可能重叠。
- 图表固定生成 3 项指标；饼图/折线图的类别数量需在属性面板中修改现有三项，不能增删。
- 占位数据会写入内容版本，插入即视为一次内容编辑。
