# TASK-EDIT-004：排列功能区补齐（对齐 / 分布 / 旋转 / 锁定）

| 项目     | 内容                                  |
| -------- | ------------------------------------- |
| 状态     | 已实现（组合/取消组合另立任务）       |
| 优先级   | P1                                    |
| 里程碑   | V0.2 专业编辑功能区                   |
| 预估     | 1–2 人日                              |
| 依赖     | 无                                    |
| 需求依据 | TRS 4.4.4“排列”功能区、4.4.1 交互能力 |

## 1. 背景

TRS 要求“排列”功能区提供图层顺序、锁定、组合/取消组合、对齐、等距分布和旋转。

此前“排列”只有复制、上移/下移、置顶/置底和删除。对齐与分布只存在于右侧多选面板，锁定和旋转只存在于单选属性面板；功能区本身无法完成这些操作。组合/取消组合则完全没有实现。

## 2. 目标

用户在多选后可以直接在“排列”功能区完成对齐、等距分布、旋转和批量锁定；单选时对齐相对页面，多选时对齐相对所选对象；所有操作一次一个撤销项。

## 3. 范围

### 3.1 包含

- 六个对齐命令：左/水平居中/右、顶端/垂直居中/底端。
- 水平/垂直等距分布（至少三个对象）。
- 顺时针旋转 90°（单对象；围绕对象自身中心）。
- 批量锁定/解锁（一个命令、一个撤销项）。
- 保持既有图层顺序、复制、删除按钮不变。

### 3.2 不包含：组合/取消组合

组合没有在本次实现，单独拆成 **TASK-GROUP-001**。原因：

- 它需要新的 `group` 元素类型或页面级分组元数据，以及持久化 Schema、复制/粘贴、删除不变量、动画归属和导出分组映射。
- 用“选中集合”伪装分组可以做出按钮，但导出的 PPTX 仍是散开的独立对象，会夸大兼容能力，违反“不得以无响应或伪能力按钮占位”。
- 正确的分组还要定义进入/退出组、组内单选、组整体缩放与旋转的坐标语义，工作量远大于功能区接线。

在此之前，功能区不显示组合/取消组合按钮。

## 4. 设计

### 4.1 对齐

- 单选：`align-element`，相对页面。
- 多选：`align-elements`，相对所选对象的外接框（与右侧多选面板一致）。
- 锁定对象不参与移动；全部锁定时按钮禁用。
- 每个按钮只动一个轴，避免“居中”同时改 X/Y 的歧义。

### 4.2 分布

- `distribute-elements`，水平/垂直等距；少于三个可移动对象时禁用。
- 锁定对象由命令跳过。

### 4.3 旋转

- 单选、未锁定时，用 `transform-element` 把角度加 90°，并归一化到 `0–359999` 毫弧度；帧不变。
- 多选旋转会围绕组中心改变每个对象的坐标，属于另一套语义，本次不做，按钮在多选时禁用。

### 4.4 锁定

新增 `set-elements-lock` 批量命令：一次写入所有选中对象，锁定时不检查对象当前锁定状态；一个撤销项。

### 4.5 UI

`src/features/editor/ArrangeToolbar.tsx`：

- 两组图标按钮：对齐（6 个）、分布（2 个），加旋转和锁定两个独立按钮。
- 工具提示写明“相对页面”或“相对所选对象”，以及分布至少三个、旋转只作用于一个对象。
- 图标按钮保持 30px 高，和 48px 的功能区行高对齐。

## 5. 验收

- **AC-1** 单选对象点左对齐，对象贴页面左边；多选两个对象点左对齐，两者左边对齐到这一组的外接框。
- **AC-2** 三个对象水平等距后，相邻间距相等；两个对象时分布按钮禁用。
- **AC-3** 单选旋转 90° 连续四次回到原角度；多选时旋转禁用。
- **AC-4** 多选三个对象点锁定，一次撤销全部解锁。
- **AC-5** 锁定对象不参与对齐/分布/旋转，全部锁定时相关按钮禁用。
- **AC-6** 所有操作只产生一个撤销项，内容版本不变。

## 7. 已知边界

- 旋转只支持单对象 90° 步进；自由角度仍用属性面板输入。
- 多选旋转、组整体缩放、组合/取消组合未实现（TASK-GROUP-001）。
- 图层顺序按钮仍只作用于“最后选中的对象”，不是整组。
