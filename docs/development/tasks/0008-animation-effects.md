## 1. 背景

TRS 4.4.5 要求出现、淡化、飞入、浮入、劈裂、擦除、缩放、强调脉冲和消失九种效果，覆盖进入/强调/退出三个阶段，并支持复制动画。

此前只实现了出现、淡化和飞入三种进入效果，阶段固定为 `entrance`；动画工具栏是三个固定按钮，没有复制动画，动画窗格的效果名也是硬编码的三元表达式。导出仍然不写入原生动画，报告会逐页说明，这一点没有变化。

## 2. 目标

用户可以在动画工具栏选择九种效果并添加；阶段由效果自动决定，不再出现“退出效果却标成进入”的错误状态；可以复制一条动画并保持顺序；画布预览覆盖所有效果；旧项目可以直接打开。

## 3. 范围

### 3.1 包含

- 九种效果：出现、淡化、飞入、浮入、劈裂、擦除、缩放、强调脉冲、消失。
- 三个阶段：进入、强调、退出，由效果派生。
- 动画工具栏改为“效果选择 + 添加”，按阶段分组显示。
- 复制动画命令：副本紧跟源动画，新 id，保留效果、计时、开始方式和方向。
- 画布预览新增 CSS：浮入、劈裂、擦除、缩放、脉冲、消失。
- Schema 升到 v16，`15 → 16` 迁移；已有动画（全部进入）保持有效。
- 动画窗格显示阶段与中文效果名。

### 3.2 不包含

- PPTX 原生动画写入（TASK-ANIM-002）。
- 运动路径、触发器、持续时间曲线、逐字/逐对象序列。
- 除飞入之外的逐效果方向参数（浮入固定从下、擦除固定从左、劈裂固定从中间）。
- 动画的批量编辑或跨页复制。

## 4. 设计

### 4.1 阶段由效果派生

`src/core/document-model/animation.ts`：

```ts
phaseForEffect(effect): "entrance" | "emphasis" | "exit"
```

- 出现/淡化/飞入/浮入/劈裂/擦除/缩放 → 进入。
- 强调脉冲 → 强调。
- 消失 → 退出。

`add-animation` 不再接受调用方传入阶段，`set-animation` 改变效果时同步重算阶段。Schema 在文档校验时拒绝阶段与效果不一致的记录（`ANIMATION_PHASE_MISMATCH`），避免旧数据或手写文件产生矛盾状态。

### 4.2 Schema 16

效果枚举从 3 种扩到 9 种，阶段从字面量 `"entrance"` 扩为三值枚举。`15 → 16` 迁移只改版本号：旧动画的阶段仍是 `entrance`，与新枚举兼容；没有动画的文稿保持没有时间线。固定样例见 `v16-document.json`（强调脉冲）。

### 4.3 UI

- 工具栏：`<select>` 按进入/强调/退出分组，旁边“添加”按钮；不再用九个占位按钮。
- 计时区：效果变化后阶段自动更新；方向仍只对飞入显示。
- 动画窗格：显示“进入/强调/退出 · 单击时 · 0.6 秒”和中文效果名。
- 复制动画：按钮在删除动画旁，禁用条件是没有选中动画。

### 4.4 预览

`SlideElementFrame` 已带 `animation-${effect}` 类；本次补齐六个 CSS 关键帧：

- 浮入：下方 18px + 淡入。
- 劈裂：纵向从中间展开。
- 擦除：从左向右揭开。
- 缩放：0.82 → 1 + 淡入。
- 脉冲：1 → 1.08 → 1。
- 消失：1 → 0。

预览是临时 UI 状态，不进入文档、撤销栈或保存状态。

## 5. 验收

- **AC-1** 九种效果都能添加，窗格显示正确的中文名称与阶段。
- **AC-2** 添加强调脉冲后阶段为 `emphasis`，添加消失后为 `exit`；把脉冲改成淡化后阶段回到 `entrance`。
- **AC-3** 复制动画后顺序紧跟源动画，id 不同，参数一致；一次撤销恢复。
- **AC-4** 旧 v15 项目打开后动画仍有效；手写阶段与效果不一致的文件被 Schema 拒绝。
- **AC-5** 六种新效果在画布预览中有可见动作，预览结束元素恢复原状。
- **AC-6** 锁定对象不能添加或复制动画。
- **AC-7** 九种效果都写入原生 `<p:timing>`；图表因没有稳定对象名而跳过，报告逐页说明。

## 7. 已知边界

- 九种效果已写入原生 `<p:timing>`；图表动画仍跳过并报告。
- 阶段与效果是固定映射，不支持“同一效果用于不同阶段”。
- 方向只对飞入生效；其他效果的进入方向固定。
- 预览是简化动画，不等同于 PowerPoint 的完整时间线渲染。
