## 1. 背景

TRS 4.4.4 要求“开始”功能区提供查找、替换和全选。此前编辑器没有搜索能力，用户只能逐页肉眼看；多选只能靠框选或逐个 Ctrl 点击。

## 2. 目标

用户可以在整个文稿中查找文字、跳转到具体出现位置、逐条或一次性替换；全选可以选择当前页所有未锁定对象；所有替换都可以撤销，已审核内容改写后回到待确认状态。

## 3. 范围

### 3.1 包含

- `Ctrl+F` 或“开始”功能区查找按钮打开查找替换浮层。
- 全文稿搜索文本对象，默认不区分大小写，可切换区分大小写。
- 结果列表显示页码、上下文片段和高亮匹配；点击跳到对应页并选中对象。
- 上一个/下一个（`Shift+Enter` / `Enter`），单项替换，全部替换。
- 替换写回标题、正文、内容块卡片和普通文本；内容绑定文本按内容变更处理。
- 全部替换是一个事务、一个撤销项。
- `Ctrl+A` 选择当前页所有未锁定对象。

### 3.2 不包含

- 搜索表格单元格、图表标签、演讲备注和文档标题栏（它们有各自的编辑规则，后续另立范围）。
- 正则表达式、整词匹配、仅当前页、跨项目搜索。
- 画布上直接高亮匹配子串（结果列表提供片段，选中对象提供上下文）。
- 查找历史、搜索替换预览。

## 4. 设计

### 4.1 搜索模型

`src/core/commands/text-search.ts`：

```ts
findTextMatches(document, query, { matchCase }): TextMatch[]
buildReplaceAllEdits(document, query, replacement, { matchCase }): TextReplaceEdit[]
replaceAllOccurrences / replaceOccurrence
```

- 转义查询串后构造 `RegExp`，大小写不敏感使用 `gi`。
- 匹配偏移是 UTF-16 下标，结果按页、元素、出现顺序排列。
- 替换使用回调函数，`$&`、`$1` 按字面写回，不被正则引擎解释。
- 全部替换按元素生成一条完整文本编辑，避免逐条替换导致偏移漂移或重复写同一元素。

### 4.2 命令

```ts
{ type: "replace-text-edits"; edits: TextReplaceEdit[] }
```

- 跨页批量命令；先解析并校验所有目标，再统一写入，坏 id 不会留下半替换状态。
- 复用从 `edit-text` 抽出的 `applyTextEdit`：同步标题/正文、内容块卡片、`syncMetricText`，清空旧 runs，内容绑定页标记 `changed`。
- 域名按目标计算：全部是普通文本为 `design`，包含标题/正文/指标卡片为 `content`，混合为 `both`。
- 一次命令一个事务、一个撤销项。

### 4.3 UI

`src/features/editor/FindReplaceBar.tsx`：

- 浮层固定在画布右上角，不遮挡属性面板。
- 结果最多展示 50 条，超出只在计数中体现；每条显示页码与匹配上下文。
- 点击结果切换页面并选中对象；替换后结果随文档重算。
- 输入框内 `Enter` 下一个、`Shift+Enter` 上一个、`Esc` 关闭。
- 全局 `Ctrl+F` 打开，`Ctrl+A` 全选当前页未锁定对象。

## 5. 验收

- **AC-1** 输入“岳阳”能列出全文稿所有匹配，页码和片段正确，中文偏移不漂移。
- **AC-2** 区分大小写开关改变结果数量。
- **AC-3** 点击结果会切到对应页并选中对象。
- **AC-4** 单项替换只改当前出现位置，不误改同元素的其他匹配。
- **AC-5** 全部替换一次完成，撤销一次全部恢复。
- **AC-6** 标题/正文/指标卡片被替换后内容版本递增，页面状态变为 `changed`。
- **AC-7** 普通装饰文本替换只增加设计 revision，不改内容版本。
- **AC-8** 替换值包含 `$&` 时按字面写回。
- **AC-9** 目标 id 失效时整批拒绝，文档不变。
- **AC-10** `Ctrl+A` 只选当前页未锁定对象；文本框内不触发。

## 7. 已知边界

- 只搜索文本元素。表格单元格、图表标签、演讲备注和文档标题不在范围内，避免替换到无法安全写回的位置。
- 锁定文本可以被搜索到，但替换会跳过并在状态里报告跳过数量；单项替换会提示先解锁。
- 不做画布内子串高亮；结果列表的片段是当前定位匹配的主要依据。
- 替换会清空文本的局部强调（runs），与手动编辑文本的行为一致。
- 正文替换沿用 `edit-text` 的规则：正文元素带结构化块时会把正文重建为单段，这与在属性面板里直接修改正文一致。
- 没有“替换前预览”；全部替换依赖撤销，内容绑定页会被标记为待确认。
