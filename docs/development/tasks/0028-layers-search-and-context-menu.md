## 1. 背景

TASK-EDIT-006 把图层面板补成了可拖放、可锁定、可多选的列表，但对象一多仍有两个缺口：

- **找不到**：一页十几个对象时只能靠肉眼滚动和时间顺序翻。图层名称是从文字/替代文本推导出来的，用户知道内容却不知道该滚到哪。
- **高级操作藏得深**：置顶、置底、上移、下移、组合、取消组合分别散在右侧属性面板和“排列”功能区；对象多时来回切换成本高，键盘用户更是只能靠属性面板。

同时，可见性（眼睛）和重命名需要新的 Schema 字段（`hidden`/`name`）和导出行为，属于另一条依赖链。本次只做**不改变文档结构**的能力：搜索、右键菜单、键盘层级移动。

## 2. 目标

- 用名称或对象类型即时过滤图层，结果数量可见，一键清除。
- 右键任意图层行即可完成层级、复制、锁定、组合/取消组合和删除；一次操作仍然一个命令、一个撤销项。
- 键盘可以在图层之间移动（Alt+↑/↓ 调一层）并打开同一个菜单（Shift+F10 / 菜单键），菜单支持方向键和 Esc。
- 搜索只影响显示，不修改文档、不改变选择，也不产生 revision。

## 3. 范围

### 3.1 包含

- 图层面板工具条下的搜索框：
  - 匹配派生名称与对象类型（如“图片”“矩形”），不区分大小写。
  - 显示“匹配数 / 总数”；无结果时提供“清除搜索”。
  - 搜索期间禁用拖动排序（筛选后的列表没有稳定的相邻落点），但点击、多选、键盘移动和右键菜单仍可用。
  - 工具条的“全选”只选择当前匹配的图层。
- 右键菜单（`LayerContextMenu`）：
  - 置于顶层 / 上移一层 / 下移一层 / 置于底层。
  - 复制、锁定/解锁、组合、取消组合、删除。
  - 菜单按当前选择块工作：多选或整组作为一块，一次命令一个撤销项。
  - 根据位置、锁定、是否已分组、组是否完整决定禁用状态。
  - 点击空白或 Esc 关闭；方向键在菜单项之间移动；关闭后焦点回到原图层行。
- 键盘层级：聚焦图层行后 Alt+↑/↓ 将当前块上移/下移一层；锁定的块不发送命令。
- 行上增加 `aria-keyshortcuts`，底部提示改成两行（拖动、Alt 层级、Shift 连选 / 右键、Del）。
- 纯逻辑抽到 `layer-order.ts`：`filterLayerRows`、`blockMoveIndex`、`layerMenuState`、`selectedGroup`。

### 3.2 不包含

- 可见性和图层重命名：需要 Schema 字段、迁移、画布/缩略图/导出过滤，单独任务。
- 搜索历史、跨页搜索、按颜色/位置搜索。
- 拖动排序时的搜索筛选落点（搜索期间直接禁用拖动）。
- 菜单里的“重命名”“隐藏”项。
- 触摸长按菜单（右键菜单通过 contextmenu 事件，触屏长按由 WebView 决定）。

## 4. 设计

### 4.1 搜索是视图状态

搜索词只存在组件本地 state，不进入文档、store 或撤销栈。`filterLayerRows` 同时匹配 `fullElementName`（文本/替代文本/图标名/类型名）和 `elementKind`；空格查询视为空。选择状态不被搜索清除，因此工具条仍显示“已选 a / b”（b 是总对象数），搜索框旁额外显示“匹配数 / 总数”，避免把两者混为一谈。

搜索期间拖动被禁用：落点按可见行计算，而命令需要绝对 Z 序下标，筛选后的相对位置会产生用户无法预期的移动。提示文案和 `cursor: default` 明确这一点。

### 4.2 菜单块与命令

`layerMenuState` 用与拖动相同的 `dragBlockIds` 计算当前块（右键行已选中时是选择，未选中时是行或整组），并一次性算出：

- 四个方向是否可移动（位置边界 + 锁定）；
- 复制/删除是否可用；
- 组合是否可用（至少两个、均未锁定、均未分组）；
- 取消组合是否可用（选择恰好等于一个组）。

组件只负责渲染和发命令。层级移动统一走 `reorder-elements`（块级），不会出现逐对象循环导致多个撤销项的情况。非相邻块在执行“上移/下移”时会被压到新位置，与拖动整块的行为一致。

### 4.3 键盘与位置

- Alt+↑/↓：阻止默认和冒泡，避免同时触发画布微移；锁定块直接忽略。
- Shift+F10 / ContextMenu：在行下方打开菜单，位置按窗口边界收拢。
- 菜单打开后聚焦第一个可用项；↑/↓ 循环；Esc 关闭并把焦点还给原行。
- 鼠标右键同样先把焦点放到行上，关闭菜单后键盘焦点不会丢到 body。

## 5. 验收

- **AC-1** 输入“图片”只剩图片行，输入对象内容片段能匹配对应文本；显示匹配数/总数。
- **AC-2** 无匹配时显示空状态，“清除搜索”恢复完整列表并把焦点放回搜索框。
- **AC-3** 搜索期间点击/Shift 连选/方向键/右键菜单仍然工作；尝试拖动不产生命令。
- **AC-4** 右键单行显示九项操作；置顶/上移/下移/置底在边界处正确禁用。
- **AC-5** 右键多选或整组，“置于底层”只发一条 `reorder-elements`，撤销一次整体恢复。
- **AC-6** 锁定块的层级、复制、删除全部禁用，“锁定”变为“解锁”。
- **AC-7** 只有选择恰好是一个完整组时“取消组合”可用；普通多选只能“组合”。
- **AC-8** Shift+F10 打开菜单，方向键移动焦点，Esc 关闭后焦点回到原行；Alt+↑/↓ 对锁定块不发命令。
- **AC-9** 浅色主题下搜索框、菜单、禁用项和分隔线对比度可读。

## 7. 已知边界

- 不做可见性/重命名，见 3.2；它们需要 v24 之后的 Schema 版本和导出策略。
- 搜索词不持久化，切换标签页后清空；切换页面时保留，方便跨页找同类对象。
- 菜单的层级移动对非相邻块会压成连续块（与拖动一致）。
- Alt+↑/↓ 在个别系统/输入法下可能被占用；右键菜单和属性面板仍提供同样能力。
- 搜索期间不能拖动排序，需要先清除搜索。
