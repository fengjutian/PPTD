## 1. 背景

TRS 4.4.4 要求“开始”功能区提供粘贴、剪切、复制和格式刷，并明确：不能访问系统剪贴板时应降级为应用内剪贴板。

在此之前，复制和粘贴只有 `Ctrl+C` / `Ctrl+V` 快捷键，功能区没有按钮；剪贴板里存的是元素 id，不是对象快照。这带来三个问题：

1. 复制后删除原对象，粘贴就找不到来源，只能提示“剪贴板中的对象不在当前页面”。
2. 跨页粘贴依赖来源页的元素，无法把对象带到其他页面或项目。
3. 功能区看不到剪贴板状态，用户不知道有没有东西可粘贴。

## 2. 目标

用户可以在“开始”功能区剪切、复制和粘贴对象；复制后删除来源仍能粘贴；跨页粘贴文本、图片、形状、线条和图标；表格/图表因依赖本页内容块而给出明确提示；每次粘贴是一个撤销项，并自动选中新副本。

## 3. 范围

### 3.1 包含

- 功能区新增“剪切 / 复制 / 粘贴”按钮，并显示可用状态。
- 应用内剪贴板保存不可变元素快照，复制后删除来源仍可粘贴。
- 剪切 = 拍照 + 一个删除命令；整次剪切一个撤销项。
- 粘贴生成新 id，副本归属用户，连续粘贴按 0.2 英寸递增偏移。
- 粘贴后选中新副本。
- `Ctrl+X` 剪切快捷键。
- 表格/图表跨页粘贴时拒绝并提示原因。

### 3.2 不包含

- 系统剪贴板与其他应用互通（需要新的 Tauri 插件与权限）。
- 粘贴动画（动画仍按元素 id 挂在页面上，本任务不复制时间线）。
- 粘贴到其他项目或跨窗口。
- 图片二进制去重（快照共享同一 data URL / 资源引用）。

## 4. 实现

### 4.1 剪贴板状态

`App` 保存 `{ elements: SlideElement[]; pastes: number }`：

- `elements` 直接引用当前文档中的不可变元素对象。文档每次修改都会产生新对象，旧引用不会被原地改写，因此无需深拷贝大图片。
- `pastes` 记录连续粘贴次数，用于计算偏移；新的复制或剪切把它归零。
- 剪贴板只在内存中，关闭窗口即清空。

### 4.2 命令

新增设计域命令：

```ts
{
  type: "paste-elements";
  slideId: SlideId;
  elements: SlideElement[];
  offsetEmu?: Emu;
}
```

- 复用既有的 `copyElementForPaste`：新 id、加偏移、文本转 `decorative` 并去掉内容块绑定、图片复制 source 引用。
- 副本强制 `origin: "user"`、`locked: false`。
- 粘贴追加到页尾，保持原有相对顺序。
- 每次粘贴只产生一个设计事务；内容版本与内容哈希不变。

### 4.3 内容块边界

表格和图表是页面内容块的视图，不是独立副本。粘贴到不含对应内容块的页面会生成无法导出的悬空引用，因此命令返回 `PASTE_REQUIRES_CONTENT_BLOCK`，UI 提示“表格或图表只能在包含其内容块的页面粘贴”。

文本的绑定在复制时已经断开，所以可以自由跨页；图表/表格在本页内复制不受影响。

### 4.4 UI 与快捷键

- “开始”功能区顺序：剪切、复制、粘贴、删除对象、文本格式。
- 没有可剪对象时剪切/复制禁用；剪贴板为空时粘贴禁用。
- `Ctrl+X` 新增；`Ctrl+C` / `Ctrl+V` 改为使用快照剪贴板。
- 粘贴后由 store 选中刚追加的副本。

## 5. 验收

- **AC-1** 选中两个对象复制后删除，仍能粘贴出两个新对象。
- **AC-2** 剪切三个对象后，撤销一次全部恢复；剪贴板仍可粘贴。
- **AC-3** 连续粘贴三次，副本依次偏移 0.2 / 0.4 / 0.6 英寸，且每次只增加一个撤销项。
- **AC-4** 文本粘贴到另一页后是 `decorative`，不再绑定原页的内容块。
- **AC-5** 表格/图表粘贴到不含内容块的页面时被拒绝，状态栏给出原因，文档不变。
- **AC-6** 粘贴不改变内容版本或内容哈希。
- **AC-7** 剪贴板为空时粘贴按钮禁用，快捷键给出提示而不是静默失败。
- **AC-8** 锁定的来源对象不会进入剪贴板。

## 6. 测试

- `src/core/commands/clipboard.test.ts`：快照粘贴、偏移、z-order、内容块拒绝、非法参数。
- `src/store/clipboard.test.ts`：一次撤销、粘贴后选中副本。
- `src/features/editor/keyboard-shortcuts.test.ts`：`Ctrl+X` 与既有快捷键不冲突。

## 7. 已知边界

- 剪贴板不进入系统剪贴板，不能与其他应用互贴；后续接 Tauri clipboard 插件时只需替换 App 的存储层，命令不变。
- 剪贴板只属于当前项目：切换项目会清空，避免粘贴出引用了旧项目资源、却在新项目里读不到的图片。
- 动画不随对象粘贴复制；需要时另立任务把动画快照一并放入剪贴板。

- 表格/图表目前不能跨页粘贴；若将来允许，需要在目标页复制内容块并明确标注为内容变更。
