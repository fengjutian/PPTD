# TASK-EDIT-008：图层可见性与重命名

| 项目     | 内容                                               |
| -------- | -------------------------------------------------- |
| 状态     | 已实现                                             |
| 优先级   | P1                                                 |
| 里程碑   | V0.1 专业编辑功能                                  |
| 预估     | 1–2 人日                                           |
| 依赖     | TASK-EDIT-006、TASK-EDIT-007                       |
| 需求依据 | TRS 4.4.4 排列功能区、7.1 左侧面板图层树；ADR 0104 |

## 1. 背景

TASK-EDIT-006/007 之后，图层可以拖放、搜索、右键操作和键盘调层级，但还缺两件专业编辑器的基础能力：

- **可见性**：想暂时移开一个底板、装饰图或旧版本文案时，只能删除（再靠撤销找回来）或挪到画布外。删除会动内容引用，挪走会留下越界对象。
- **命名**：图层名是从文字或替代文本推导出来的；两个同文案文本框、无 alt 的图片（都叫“图片”）无法区分。模板生成的“背景图”“装饰线”也需要稳定的人工名字。

两者都不是内容：不改变标题、正文、数字或引用。因此可以做成设计域的编辑状态，并随项目保存/撤销。

## 2. 目标

- 图层面板每行有眼睛开关；隐藏对象不出现在画布、缩略图、评审渲染和框选结果里，但仍留在图层列表，可恢复。
- 双击图层名或 F2/右键“重命名”进入行内编辑；Enter/失焦提交，Esc 取消；一次提交一个撤销项。
- Schema 升到 v25，旧文档迁移后全部可见、继续使用推导名。
- 导出使用去隐藏快照，并在报告与前置检查里明确说明哪些对象没有写入。

## 3. 范围

### 3.1 包含

- `ElementBase.name?: string`（1–80 字符、单行、缺省为推导名）与 `hidden?: boolean`（缺省可见）。
- Schema v25：`base` 增加两个可选字段，`24 → 25` 迁移、v24 固定夹具与迁移测试；名称空白/超长/多行的拒绝测试。
- 命令：
  - `rename-element { slideId, elementId, name }`：空白清除名称；规范化空白；超过 80 抛 `ELEMENT_NAME_TOO_LONG`；允许重命名锁定对象；名称未变化时不产生命令/撤销项。
  - `set-elements-hidden { slideId, elementIds, hidden }`：批量、设计域、允许隐藏锁定对象；`hidden=false` 删除字段；状态未变化时不产生命令。
- UI：
  - 行内眼睛（显示/隐藏块）、隐藏行降不透明度、`aria-pressed`/`aria-label`。
  - 底部“显示全部隐藏图层（n）”一键恢复，批量操作仍是一个撤销项；状态栏显示“可见对象数 · 隐藏数”。
  - 选中隐藏对象时，属性面板顶部说明它在画布/缩略图/导出中不可见，并提供“显示图层”。
  - 双击名称、F2、右键“重命名”进入行内输入；Enter/失焦提交，Esc 取消；空值恢复推导名；输入中禁用拖动。
  - 右键菜单新增“重命名”和“隐藏/显示”。
  - 搜索匹配自定义名称；行 aria-label/title 使用自定义名称。
- 渲染过滤：画布、`SlideScene`（幻灯片缩略图）、`presentation-renderer` 评审图、框选、Ctrl+A、taste lint。
- 导出：`withoutHiddenElements` 快照贯穿图片框形、渐变、动画、一致性校验、素材来源和模板贴合度；前置检查逐页提示隐藏对象未导出；导出报告带同一条 warning。
- 复制/粘贴与复制对象：副本恢复可见（隐藏是源对象的编辑状态），保留自定义名称。
- 文档：本任务、ADR 0104、v0.1-plan 行。

### 3.2 不包含

- PPTX 原生隐藏形状（`<p:cNvPr hidden="1">`）：见 ADR 0104，另立任务。
- 自定义图层名写入 PPTX 的 `cNvPr name`：会和原生动画的目标名冲突，另立任务。
- 组级可见性/组名：选择组仍是页面元数据，成员逐行控制。
- 隐藏对象的动画单独暂停/清理（动画保留在数据里，导出时不写入）。
- 隐藏对象在导出预览对话框中的逐对象列表（只有逐页数量警告）。
- 重命名历史、名称唯一性约束。

## 4. 设计

### 4.1 模型与迁移

```ts
interface ElementBase {
  // ...
  name?: string; // 1–80 字符，单行
  hidden?: boolean; // 缺省可见
}
```

`hidden: false` 不落盘，避免旧数据和新数据出现两种“可见”表示。迁移 `24 → 25` 只校验并用 v24 schema 解析，不添加任何字段；因此 v24 文档打开后仍全部可见、名称仍由内容推导。

### 4.2 命令与撤销

`rename-element` 与 `set-elements-hidden` 都在 `commands.ts` 里、元素命令的锁定守卫之前处理，所以锁定对象也可以改名/隐藏——否则一个锁定后隐藏的对象永远无法恢复。

`commandDomain` 会比较规范化后的名称、以及全部目标当前的隐藏状态：没有变化返回 `null`，store 不会压入空撤销项。隐藏批量命令只产生一个撤销项。

### 4.3 可见性与选择

- 隐藏不删除对象，也不自动改变选择：图层行仍可点选，属性面板仍可编辑；只是画布上没有可点的实体。
- 框选、Ctrl+A 只处理可见对象；隐藏对象只能从图层列表选中。
- 幻灯片缩略图和评审图与画布共用过滤规则，避免“画布隐藏了但缩略图还显示”。
- 图层缩略图仍绘制隐藏对象（降透明度），否则用户无法辨认要恢复的是哪一个。

### 4.4 导出

导出先构造 `withoutHiddenElements(document)`：

- 逐页移除隐藏元素；
- 只保留成员全部可见的组；
- 只保留目标可见的动画；
- 后续所有 pass 都基于这份快照，图片顺序、渐变按 id 查找、动画目标和一致性校验不会错位。

前置检查按页追加 `hidden-not-exported` warning；导出报告如果拿到的是外部预检结果、缺少这条 issue，会补一条总数量 warning。这与 ADR 0104 的“不写原生隐藏形状”一致。

### 4.5 重命名交互

- 名称输入初始值为自定义名（没有则为空），占位符显示推导名；空提交即恢复推导名。
- `editingIdRef` 同步记录正在编辑的行：Enter 提交后输入框卸载时可能再触发一次 blur，ref 保证不会重复发命令。
- Enter 提交后把焦点还给行；失焦提交不抢焦点，避免点击另一行时焦点被拉回。
- 搜索、拖动、右键菜单在编辑期间不抢输入框。

## 5. 验收

- **AC-1** 点击眼睛隐藏对象：画布、缩略图、框选和 Ctrl+A 都不再包含它；图层行仍存在且降低不透明度。
- **AC-2** 再次点击恢复；隐藏/显示各是一个撤销项，隐藏两次不产生第二个撤销项。
- **AC-3** 隐藏锁定对象、再恢复，不会被 `ELEMENT_LOCKED` 阻止；底部“显示全部隐藏图层”一次恢复所有隐藏对象。
- **AC-4** 双击名称/F2/右键“重命名”进入输入；Enter 提交、Esc 取消、失焦提交；空白恢复推导名；超长被限制在 80。
- **AC-5** 重命名不改变内容、内容哈希和导出几何；撤销一次恢复原名。
- **AC-6** 复制隐藏对象得到可见副本；自定义名称保留。
- **AC-7** v24 文档迁移后全部可见且没有名称；v25 文档保存再读名称/隐藏状态不丢。
- **AC-8** 导出含隐藏对象的页面：隐藏对象不在 slide XML 中，报告和前置检查都提示；包校验和一致性校验通过。
- **AC-9** 浅色/深色下隐藏行、眼睛、行内输入和右键菜单可读。
- **AC-10** 选中隐藏对象时属性面板出现“图层已隐藏”说明和“显示图层”；状态栏同时显示可见数与隐藏数。

## 7. 已知边界

- 导出的 PPTX 不含隐藏对象；PowerPoint 里无法再取消隐藏。ADR 0104 已记录，报告会提示。
- 自定义名称不写入 PPTX，选择窗格仍显示 element id；原生动画依赖这个 id，不能直接改名。
- 隐藏对象如果被其他对象/动画引用，只从导出快照移除，不修改项目数据。
- 质量门（`presentation-quality-gate`）仍按完整对象集分析；它用于 AI 生成期，隐藏通常发生在其后。
- 没有组级隐藏/组名，也没有“隐藏全部某类型”的批量入口。
