## 1. 背景

“设计”功能区要求提供页面尺寸，但此前页面尺寸只在属性面板只读展示，文档也没有修改命令。用户新建的 16:9 文稿无法改成 4:3，导入模板的页面尺寸也无法在应用内调整。

## 2. 目标

用户可以在“设计”功能区选择 16:9、4:3、16:10 预设，或输入自定义宽高（英寸）；修改作为一次设计事务进入撤销栈；内容、审核状态和对象坐标不被静默改写。

## 3. 范围

### 3.1 包含

- `set-page-size` 设计域命令，校验 1–56 英寸（PowerPoint 的页面尺寸边界）。
- “设计”功能区预设按钮 + 宽/高英寸输入 + 应用。
- 越界对象计数提示；导出前预检仍会逐对象报告。
- 组件、命令、store 与导出测试。

### 3.2 不包含

- 修改页面尺寸时自动缩放对象（“确保适合”/“最大化”）。
- 按内容重排版（已有 `relayout-slide`，但不会因页面尺寸自动触发）。
- 母版/版式随新尺寸重建；导入模板的背景图仍按原坐标绘制。
- 页面方向切换（横/纵）的专门入口；可通过交换宽高实现。

## 4. 设计

### 4.1 模型与命令

`src/core/document-model/page-size.ts`：

```ts
PAGE_SIZE_PRESETS; // 16:9 13.333×7.5、4:3 10×7.5、16:10 13.333×8.333
pageSizeFromInches(); // 英寸 → 整数 EMU，越界返回 undefined
matchPageSizePreset(); // 精确匹配当前尺寸
MIN_PAGE_SIZE_IN / MAX_PAGE_SIZE_IN;
```

命令：

```ts
{
  type: "set-page-size";
  pageSize: {
    width: Emu;
    height: Emu;
  }
}
```

- 设计域；只改 `document.pageSize`，不动元素、内容、审核状态。
- 宽高必须是安全整数 EMU 且落在 1–56 英寸内，否则 `INVALID_PAGE_SIZE`。
- 一次命令一个撤销项。

### 4.2 UI

`src/features/editor/PageSizeControls.tsx`：

- 三个预设按钮，当前尺寸精确匹配时高亮；点击立即应用。
- 宽/高输入（英寸，两位小数），`Enter` 应用，`Esc` 复位。
- 输入非法时显示行内错误，不写文档。
- 统计所有页面中超出新页面的对象数量，提示“对象不会自动缩放”。
- 属性面板的尺寸保持只读，避免出现两个写入口。

## 5. 验收

- **AC-1** 选择 4:3 后页面变为 10×7.5 英寸，画布、缩略图和导出同步。
- **AC-2** 修改页面尺寸只递增设计 revision，内容哈希和审核状态不变。
- **AC-3** 对象坐标不变；超出新页面的对象在控件和导出预检里都有提示。
- **AC-4** 一次修改一个撤销项，撤销恢复原尺寸。
- **AC-5** 0.5 英寸、57 英寸、小数 EMU 被拒绝，文档不变。
- **AC-6** 导出的 `presentation.xml` 写入新的 `sldSz`。
- **AC-7** 预设按钮只在精确匹配时高亮，自定义尺寸不会误亮。

## 6. 测试

- `src/store/page-size.test.ts`：一次撤销、设计 revision。
- `src/features/editor/PageSizeControls.test.tsx`：预设、当前值、越界计数。
- `src/features/pptx-export/export-pptx.test.ts`：`sldSz` 写入新尺寸。

## 7. 已知边界

- 不自动缩放对象；改成更小的页面后，原来贴边的对象会跑到页面外，需要用户自己调整或撤销。
- 模板版面按原坐标绘制，换尺寸不会重建母版；导入模板的文稿建议使用原尺寸。
- 单位固定为英寸；属性面板仍可按用户偏好显示英寸/厘米。
