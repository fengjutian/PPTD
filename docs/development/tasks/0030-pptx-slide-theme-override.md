# TASK-IMPORT-002：PPTX 页级主题、背景与占位符样式继承

| 字段 | 内容                      |
| ---- | ------------------------- |
| 状态 | 已实现                    |
| 日期 | 2026-10-26                |
| 依赖 | TASK-IMPORT-001、ADR 0052 |

## 1. 目标

在不改变 Level A 中性导入架构的前提下，读取幻灯片关系中的 `themeOverride` 部件，并恢复 slide → layout → master 的可表示背景和占位符文本样式。覆盖部件只替换自身声明的颜色和字体槽，未声明的槽继续继承整册主主题。

## 2. 范围

- 通过关系类型定位页级 `themeOverride`，不假设固定文件名。
- 合并覆盖主题与整册主题，并用于当前页文本、形状和连接线的颜色/字体解析。
- 解析 slide、layout、master 的纯色与主题色背景；距离页面最近的显式背景优先。
- layout/master 自身的 `themeOverride` 参与继承背景的主题色解析。
- 占位符从 layout、master 继承字体、字号、颜色、粗斜体、水平/垂直对齐、行距和项目符号；slide 显式值优先。
- 段前/段后 point 间距进入 Schema v26、画布和原生 PPTX 导出，见 ADR 0105。
- 文本框级制表位进入 Schema v27，支持左/中/右/小数点对齐并原生导出，见 ADR 0106。
- 页面切换导入支持 fade、push、wipe、split 的速度与方向；未知效果进入兼容报告。
- 文本片段外部链接支持 http、https、mailto，并以原生可编辑超链接导出；内部跳页、文件链接和其他协议进入兼容报告。
- 渐变、图片、效果背景及母版装饰对象进入逐页兼容报告，不静默丢失。
- 导入入口不再固定标为“Level A”；导入报告继续按实际跳过项展示 A/B/C 兼容等级。
- 保持源文件只读，导入结果仍为待审核的新项目。

## 3. 非目标

- 不重建母版装饰对象、渐变背景和图片背景。
- 不实现逐段独立样式、逐段独立制表位、百分比段距和完整富文本往返。
- 不承诺 PPTX 无损往返或 Level B/C 全面完成。
- 不处理对象动画、内部跳页/形状级超链接、SmartArt、OLE 和音视频；页面切换已覆盖四种领域模型效果。

## 4. 验收与测试

- 覆盖主题只提供 `accent1` 和次要字体时，当前页使用覆盖值。
- 主文本色和主要字体等未覆盖槽继续使用整册主题。
- slide 没有背景时依次继承 layout、master；显式 slide 背景覆盖继承值。
- 无法表示的背景和母版装饰对象使兼容等级降级并产生报告项。
- slide 未声明文本样式时使用最近的同一占位符样式；空 `bodyPr` 不清除继承的垂直对齐。
- Rust 导入测试、前端类型检查和导入对话框测试通过。

## 5. 实现记录

- `pptx_import.rs` 拆分主题 XML 解析与按路径读取，增加部分主题合并和页关系解析。
- 增加背景继承上下文；映射后的页面保存解析出的实际背景色。
- 增加占位符文本样式上下文，layout 优先、master 补缺，并修正无显式下划线/删除线时误清除继承值的问题。
- 增加段前/段后 point 间距；v25→v26 恒等迁移不为旧项目虚构间距。
- 增加文本框级原生制表位；v26→v27 恒等迁移不为旧项目虚构位置。
- 增加页面切换解析并直接映射到既有 `SlideTransition`，不新增持久化字段。
- 文本 run 增加受协议白名单约束的 `hyperlinkUrl`；v29 迁移到 v30 时不从显示文字猜测链接。
- 导入对话框入口改为“导入可编辑内容”，兼容级别由报告展示。
- README 明确页级主题覆盖能力和动态兼容等级。
