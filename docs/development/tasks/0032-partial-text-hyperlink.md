# TASK-TEXT-003：局部文字超链接

| 项目     | 内容                                        |
| -------- | ------------------------------------------- |
| 状态     | 已实现                                      |
| 优先级   | P1                                          |
| 里程碑   | V0.2 专业编辑功能区                         |
| 依赖     | TASK-TEXT-002 安全文本超链接往返            |
| 需求依据 | TRS 4.4.1 文本、4.4.4“插入”功能区、4.5 导出 |

## 1. 背景

`TextRun` 已经可以保存 http/https/mailto 外部链接，导入、导出和整框链接入口也已存在。此前编辑器只能给整个文本框设置链接，用户无法给标题中的某个词、引用或正文中的一句设置链接；同时“清除全部强调”会把同一 run 上的链接一起删掉。

## 2. 目标

在不改变正文和内容审核状态的前提下，让用户只给选中的文字设置、编辑或清除链接，并保证链接与其他字符格式互不误删。

## 3. 范围

### 3.1 包含

- `set-text-hyperlink` 增加可选 `range`，只处理一个文本元素内的字符区间。
- 属性面板在选中文字后提供“设置/编辑/替换所选文字链接”和“清除所选文字链接”。
- 整框链接仍可从“插入 → 超链接”设置，行为不变。
- 局部链接保留范围外的链接和范围内的粗体、颜色、下划线。
- 清除局部或全部强调时只移除粗体、颜色、下划线，保留链接。
- “已强调”列表不再把只有链接的片段算作强调；新增“已链接”提示。
- 导出继续写原生文本 run hyperlink，正文和内容哈希不变。

### 3.2 不包含

- 形状级链接、内部幻灯片跳转、文件链接和其他协议。
- 跨多个文本元素的链接范围；一个 `range` 必须且只能对应一个文本元素。
- 画布内点击跳转、链接预览或链接管理面板。
- 链接与强调之外的字符格式（斜体、字号、上下标等）进入片段模型。

## 4. 设计

### 4.1 命令边界

`set-text-hyperlink` 带 `range` 时要求 `elementIds` 只有一个元素，并复用 `assertTextRange` 检查边界和代理对；错误码为 `TEXT_HYPERLINK_RANGE_INVALID`。不带 `range` 时仍按整框链接处理。

### 4.2 片段改写

`setTextHyperlinkRange` 在范围外复制原 run，在范围内按已有着色/字重拆分并替换链接；`clearTextEmphasisRange` 使用同一套区间改写逻辑，只删除 `bold`、`color`、`underline`，保留 `hyperlinkUrl`。没有样式和链接的空 run 会被丢弃。

### 4.3 交互

属性面板读取文本框当前选区。选区覆盖的片段只有一个链接时显示“编辑”，有多个链接时显示“替换”；没有选中文字时两个按钮都禁用。链接地址在 UI 和命令层共用 `isSafeTextHyperlinkUrl`，避免前端接受文档层会拒绝的地址。

## 5. 验收

- **AC-1** 选中一段文字设置链接后，只有该范围带链接，范围外正文、强调和其他链接不变。
- **AC-2** 清除所选范围链接后，范围外链接和正文保持不变。
- **AC-3** 一个 `range` 作用于多个元素、越界、空范围或切开代理对时被拒绝。
- **AC-4** 清除局部/全部强调会保留链接，只有链接的片段不再出现在“已强调”列表。
- **AC-5** 导出仍包含原生 `<a:hlinkClick>` 关系，正文和 `contentHash` 不变。
- **AC-6** 整框链接入口保持原行为。

## 7. 已知边界

- 链接仍只接受 2048 字符以内的 http、https、mailto 地址；导入的 `file:`、内部跳页和形状级链接继续被过滤并报告。
- 选区来自属性面板文本框；用户改字后旧选区会被清空，避免把链接落到错位字符上。
- 画布和导出共用片段模型，但画布不执行链接点击。
