# 0029：底板与页脚用页面底色，分栏页用卡片

## 状态

已接受（2026-10-22）。

## 背景

重新生成后的 20 页课件仍有三种"页面自己不知道自己长什么样"的问题：

1. **黑色底板。** 第 7 页背景是白的，对比卡片下面却压着一整块 #1A1A1A 的矩形。它是 `local-scrim`：修复为了让文字离开复杂底图，给文字块盖一层底板，而底板颜色取的是 `design.background`（设计给这一页的深色），不是页面实际的白底。
2. **页脚白字白底。** 同一页的页脚是 #FFFFFF，页面是 #FFFFFF。页脚落在内容区之外，但最后一遍墨色解析仍拿底图正文区的亮度区间来算——底图是暗的，于是页脚被"修"成白色。
3. **两列裸文字。** 第 4、11、14 页是 `columns` 构图：模板给了一块白色面板，里面只有两个文本框，要点挤在上半部，下面 60% 是空的。

## 决策

1. `local-scrim` 的填充改用 `slide.background`（模板声明的页面底色或设计底色）。底板的作用是盖住底图、把页面恢复成平色，它必须和页面同色，而不是和设计稿同色。
2. 最后一遍墨色解析对页脚带（y ≥ 90%）一律使用页面底色，不再套用底图的亮度区间。页脚不在底图占位区内，探针描述的区域和它无关。
3. `columns` 页画成两张卡片：共享同一个高度，`cardFill` 填充 + 顶部 0.008 色线 + 0.035 页宽内边距，文字在卡片内垂直居中。卡片高度取 `max(内容区 50%, 两列较高者 + 内边距)`，上限是模板给的列槽高度。
4. 两列共享高度，不允许各自按自己的文字高度收缩：两张高度不同的卡片读起来是两个无关的块，不是一页对照。

## 结果

- 白色页面上的黑色底板消失；对比卡片回到页面底色上。
- 页脚在浅色页恢复深灰、在深色页保持浅色，不再出现白字白底。
- 分栏页从"两列浮字"变成两张等高的卡片，页面下半部有了结构。
- 新增 3 条行为测试：底板与页面同色、底图探针为暗时页脚仍可读、分栏页生成两张卡片。

## 未覆盖

- 深色变体页（第 15 页整页 #1A1A1A）仍然会单独出现，整册底色的一致性没有规则约束。
- 分栏卡片的最小高度是内容区的 50%，内容很少时卡片下方仍会有留白。
- 模板自带面板再叠加生成卡片时会形成双层框；这一轮没有做"模板已有面板就不再加卡片"的判断。
