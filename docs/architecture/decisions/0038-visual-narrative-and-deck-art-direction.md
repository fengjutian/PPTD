# 0038：逐页视觉叙事与整册艺术指导

## 状态

已接受（2026-10-23）。

## 背景

`layout` 和 `composition` 能决定页面属于哪类容器、使用哪种几何骨架，却不能表达观众应当如何理解一页。结果是不同语义的内容被装入相似卡片，单页规整但整册缺少叙事变化。内置主题的推荐值还可能只参与 AI 设计、没有写入最终文档；命令层的预设默认色又会覆盖模型已经选择的深浅页角色。

## 决策

1. `AiSlideDesign` 新增 `visualNarrative`：`statement`、`evidence`、`comparison`、`chronology`、`framework`、`quotation`、`scene`。它描述传播策略，不包含坐标、字号或内容文本。
2. 模型先选择视觉叙事，再选择版式、构图、层级、密度和配色角色。旧模型未返回时，前端按结构化内容块和 `SlideBrief.visualIntent` 确定性补全。
3. 构图为 `auto` 时，由视觉叙事提供首选构图；最终仍需通过内容容量校验，不能用视觉变化牺牲可读性。
4. `scene` 页在旧模型漏掉素材意图时补一个无文字的侧栏画面请求。素材仍在文档外生成，失败不阻断文稿，排版引擎拥有最终放置权。
5. 新增整册艺术指导：封面、章节与结论式页面作为深色视觉节拍，普通内容页保持浅色；连续两个节拍时第二页回到浅色，避免整册大面积压暗。该阶段只调整模板色板角色。
6. 主题推断得到的预设 ID 必须写入生成命令。命令层对携带 `palette` 的设计保留已经约束到预设色板的深浅结果；旧手工调用仍使用预设安全默认色。
7. 视觉评审新增 `repetitionScore`、`themeFitScore`、`visualFocusScore`。逐页评分可携带 `visualFocusScore`，问题类型增加 `theme-mismatch` 和 `weak-visual-focus`。旧评审响应仍可解析，缺失项明确显示“未评”。

## 边界

- 视觉叙事不是自由坐标生成；几何仍由确定性引擎负责。
- 自动配图只补 `scene` 叙事，结构化图表、时间线和密集要点不强制配图。
- 主题匹配仍以主题词启发式和用户选择为准；导入模板始终优先，不静默替换用户指定模板。
- 新评分来自视觉模型，模型不可用时不伪造分数。
