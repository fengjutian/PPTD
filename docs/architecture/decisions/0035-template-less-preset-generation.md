# 0035：不用模板，用内置主题生成

## 状态

已接受（2026-10-23）。

## 背景

AI 生成路径一直要求先选一个 PPTX 模板：`generateFromDraft` 的守卫是 `!selectedTemplate || !templateAnalysis` 就返回。内置主题预设因此只能作为"模板主题缺失时的兜底"，在界面里走不到——用户不选模板就没有任何生成入口。

## 决策

1. `generateFromDraft(mode)` 增加 `"template" | "preset"` 参数，默认仍是模板模式，原路径不变。
2. 预设模式用 `presetTemplateAnalysis(preset)` 合成一份 16:9 的模板上下文：只有页面尺寸、主题色（accent/muted/surface/primary）、字体，没有版式、没有装饰、没有示例页。设计阶段因此不会引用不存在的占位符。
3. 生成命令在预设模式下不传 `templateTheme`、`templateLayouts`、`templateDecorations`、`fontFamily`，只传 `themePresetId`；主题、字体、色板、字阶全部由预设决定。
4. 模板选择对话框增加"不用模板，用内置主题"按钮；主题 id 未选时按 AI 主题自动推断。
5. 状态栏与质检报告的名称在预设模式下显示预设名（如"纸墨"），不再显示模板名。

## 结果

- 不选模板也能生成：预设是完整的视觉系统，页面没有模板底图干扰。
- 模板路径完全保留：mode 默认为 template，原有守卫、命令字段、报告名称不变。
- 全量 641 条测试通过；typecheck 与桌面构建通过。

## 未覆盖

- 预设模式只能靠真实 AI 调用验证：Rust 侧的设计提示词收到的是空版式列表，生成质量取决于模型对"无模板"的处理，本轮没有自动化测试能覆盖。
- 预设模式没有版式资产，页面构图完全由排版引擎的默认组合决定；这比模板模式更依赖默认组合的质量。
- 没有模板底图/Logo，封面与章节页是纯色排版。
