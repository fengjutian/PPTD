# 0086 模板符合度是测量结果，不是模型评分

## 状态

已接受（2026-10-25）。

## 背景

上传模板后，模板本身会出现在每一页渲染图里，但“看得见”不等于“可验收”。视觉模型看到的是像素，无法稳定回答：

- 标题左轴是否与模板占位一致；
- 正文是否越过模板内容区；
- 字号是否回到模板占位的大小；
- 封面/章节页是否本来就允许自由构图。

只靠模型评分，会把“页内好看但偏离模板”的页面放过去；只靠规则，又无法判断视觉平衡。两者必须分工。

## 决策

### 1. 先把模板编译成可测目标

`buildTemplateReviewTarget` 把 `analyze_pptx_template` 的分析结果编译为：

- 页面归一化 0–1 坐标的 `TemplateGrid`（标题区、内容区、左右/上下边距）；
- 每个版式的标题/正文字号；
- 主题色板（仅用于评审提示词，不做确定性检查）；
- 轴语言（`left-grid` / `centered-grid`）；
- 置信度与最低符合度阈值；
- 容差：轴 0.01、纵向轴 0.005、边距 0.01、字号 1.5pt。

优先使用版式占位，而不是模板样例页：样例页常被手工调整，不代表模板网格。

### 2. 自由构图的页面不按内容轴扣分

名称匹配 `封面|标题幻灯片|扉页|章节|篇章|过渡|分隔|结束|谢谢|引用|引言|金句|cover|section|quote|closing|end` 的版式标记为 `freeComposition`。这些页面允许打破内容轴；检查直接跳过。

### 3. 只检查能从文档观察的四类偏差

| 代码                      | 严重度  | 判断                           |
| ------------------------- | ------- | ------------------------------ |
| `template-title-axis`     | error   | 标题框 x/y 超出轴容差          |
| `template-content-bounds` | error   | 正文并集超出内容区超过边距容差 |
| `template-title-size`     | warning | 标题字号与模板占位差超过 1.5pt |
| `template-body-size`      | warning | 正文字号与模板占位差超过 1.5pt |

带结构化内容块（指标、表格、图表等）的页面跳过字号检查：这些元素的字号由组件决定，不是普通正文。

### 4. 分数与阈值是确定性的

```text
score = max(0, 100 - errors × 10 - warnings × 3)
passed = checked && errors === 0 && score >= minimumFit
```

没有可检查页面时 `checked=false`、`score=0`、`passed=false`，不能把“没检查”当成通过。

置信度：

- 至少 2 个可测版式，且至少 1 个同时有标题/正文占位 → `high`，阈值 90；
- 否则 `low`，阈值 85。

只有标题的封面也算“可测版式”，但它不能单独把置信度抬到 high。

### 5. 模型评分与确定性检查合并，但后者是权威

- 评审提示词携带同一份模板目标，要求偏离轴线的页面 alignmentScore 不高于 79，并报告 `misalignment`；
- 确定性检查的 issues 以 `template-mismatch` 进入同一份 `VisualReview`，并带原始 `code`；
- 确定性 `templateFitScore` 覆盖模型可能给出的值：模型不能用一个宽松的模板分绕过实测偏差；
- 修复计划可以把标题移回模板标题区，移动是设计命令，不改内容。

### 6. 色板暂不做确定性检查

模板色板只进入评审提示词，帮助模型判断 theme fit；没有实现“元素颜色必须属于模板色板”的规则，因此 `template-palette` 代码已从类型中删除，避免一个永远不会出现的错误码。

## 后果

正面：

- 模板符合度可测、可复现，不依赖模型当天的心情。
- 封面/章节页不会被内容轴误伤。
- 报告能指出具体页、具体偏差和修复建议。
- 与评审循环共用同一份目标，不会出现“提示词说 90、代码说 85”。

代价与限制：

- 只覆盖标题轴、内容区、字号；装饰几何、图片内文字、视觉平衡仍归视觉评审。
- 需要模板分析结果里有标题/正文占位；没有占位时无法建立目标，报告为未检查。
- 版式名匹配是启发式，改名的封面可能被当成内容页。
- 色板没有确定性检查。
- 阈值 90/85 是当前经验值，需要真实模板校准。

## 验证

- `template-review-target.test.ts` 7 项：网格/字号/轴语言、无占位返回 undefined、通过页、标题偏移、正文越界、自由构图跳过、目标继承阈值。
- `design-quality-stage.test.ts` 23 项：模板目标参与评审、报告与修复路径不破坏原有降级行为。
- 全量测试、类型检查、ESLint、生产构建通过。

## 备选方案

- **只让模型打分**：不可复现，也无法给出精确修复坐标。
- **只做规则检查**：无法判断视觉平衡与模板气质。
- **把模板截图直接当背景**：会丢掉可编辑对象，不符合导出目标。
- **色板强制匹配**：模板色板常被设计系统扩展，强制会大量误报；先只作为提示词上下文。
