# 0037：稀疏页放大规则（对照页与卡片页）

## 状态

已接受（2026-10-23）。

## 背景

预设模式的六页实测暴露出同一类问题：**内容少、字号不变**。对照页两栏四条时正文 18pt、卡片只占内容区一半；卡片页四条时正文 16pt、编号 12pt，整页读起来像图注。版式本身没错，是"稀疏页仍用密集页的字号"。

## 决策

1. 对照页（columns）：
   - 条目 ≤ 4 且每条 ≤ 16 字时，正文 18 → 20pt；
   - 卡片最小高度从内容区 50% → 60%，两栏仍等高；
   - 长文案（>16 字）保持 18pt，防止放大后溢出。
2. 卡片页（grid）：
   - 同样条件（≤4 条且每条 ≤ 16 字）下正文 16 → 17pt，编号 12 → 14pt；
   - 卡片高度上限 0.24 → 0.26（内容仍决定实际高度）；
   - 卡片正文在徽标下方**垂直居中**，不再贴顶，单行卡片不再显得被截断。
3. 两条规则都以"条目数 + 字数"为条件，不改变模板/密集页。

## 结果

- 对照页与卡片页在内容稀疏时字更大、块更满，观感从"没排满"变为"留白"。
- 长文案页不受影响：仍走 18pt/16pt 与自动适配。
- 命令测试 118 条通过，全量 644 条通过。

## 未覆盖

- 16 字是启发式阈值，中英混排没有单独处理。
- 卡片页在 5–6 条时仍用密集字号，未做"中等密度"档。
- 没有按页面实际留白比例自适应，只按条目数与字数判断。
