# 0064：模板页接入页面配方

## 状态

已接受（2026-10-24）。实施见 [TASK-DESIGN-003](../development/tasks/0013-template-recipes.md)。

## 背景

ADR 0046 把“概念 → 配方 → 令牌”三层落地，但明确把模板页排除在配方之外：模板页继续走旧分支。实测结果是：

- 模板路径的 3–4 条短要点仍然画成三到四张 0.2 页高的白卡，内容停在页面上半部；
- 指标页仍然把 56pt 数字顶在一个大框里，标签固定在 0.73；
- 同一册里预设页已经用编号栏/大数字，模板页却还是卡片，视觉语言分裂。

ADR 0063 已经把 `PageChrome` 接到模板占位：模板页现在有统一的标题轴、内容区和模板墨色。配方本身只追加内容元素，不画背景、不动 Logo，也不改页序，因此可以在保留模板的前提下接管内容区。

## 决策

1. **模板页可以走配方。** `editorial-index`、`data-story`、`asymmetric-split` 不再因为 `hasArtwork` 而拒绝；只要内容装得下、页面不是 cover/section/quote，就可以在模板的内容占位内排版。
2. **模板页的 chrome 来自模板占位。** 标题框、内容区使用模板解析出的 title/body region；配方不再使用自己的 0.09/0.34 常量。
3. **模板已有表头时关闭配方的强调短线。** `PageChrome` 增加 `showRule`；模板页一律 `false`，由模板自己的标题线/装饰负责表头。配方内部的浅色分隔线仍保留，它们属于内容区。
4. **墨色以模板和底图探针为准。** 配方使用命令层解析后的 `colors.title / body`；当模板底图较暗时，强调色回退到标题墨色，分隔线回退到浅色，避免深色 accent 压在深色底图上。
5. **图片配方仍不用于模板。** `image-led` 需要自己的图片框和裁剪，和模板底图/占位的关系尚未验证，继续走旧分支。
6. **失败回退旧分支。** 配方拒绝（容量、结构化块、图片、封面）时，命令层继续走现有旧分支，不静默删改内容；`consumed` 继续做丢字守卫。
7. **封面/章节页不接入。** 模板封面通常自带完整构图，配方只处理内容页。

## 边界

- 模板背景图、Logo、装饰、母版和页脚仍由现有前置/后置逻辑处理；配方只追加内容元素。
- 内容不可变：配方只读 `SlideContent`，不新增、不改写、不重排文字。
- 模型仍只选配方/版式/颜色角色，不输出坐标和字号。
- 导出的 PPTX 仍是原生可编辑对象；模板版式引用不变。
- 不改变无概念/旧设计的输出：没有 `designConcept` 时仍走旧分支。

## 结果

- 模板路径的短要点页从白卡变为编号栏，指标页从“数字 + 远处标签”变为“数字 + 紧贴标签”。
- 预设页与模板页在标题轴、内容顶边、字号阶梯上更接近，整册不再像两套模板拼成。
- 模板自带表头不会被配方重复画一条强调线。
- 深色模板封面的白色标题不会再被 preset 的深色 primary 覆盖；未采样到底图亮度时保留模板墨色，而不是按白页翻转。
- 失败路径不变：配方不适用时仍有旧分支兜底。

## 实施结果（2026-10-24）

- 7 页模板样张：第 2/4 页编号栏、第 3 页大数字、第 5/6 页旧分支、第 7 页收束正文居中；模板底图、Logo、页眉线保留。
- 模板封面标题保持模板白色，preset 只接管字号/字阶；模板内容页标题/正文墨色保留。
- 全量前端测试 1051 项通过；类型检查、Lint、生产构建通过。视觉回归仍因本机图表渲染差异显式跳过，未更新基线。

## 未覆盖

- 模板页的 `process` / `comparison` 已由 [ADR 0065](0065-process-and-comparison-recipes.md) 接续为 `process-rail` / `comparison` 配方。
- 模板页的图片叙事（`image-led`）与模板图片占位的关系未验证。
- 模板封面/章节页仍使用模板自己的构图或旧分支。
- 视觉评审的 `changeRecipe` / `distinctivenessScore` 仍是 ADR 0046 的 P2。
