# ADR 0122：以实测页面填充和视觉锚点评分设计

## 状态

已接受（2026-10-27）。

## 背景

逐页设计已经能通过溢出、重叠、越界和低对比检查，但“检查通过”不等于“版面成立”。确定性检查只看元素是否互相冲突，不看一页实际被内容占了多少。于是标题下只有三行短句、其余三分之二空白的页面可以拿满分；过程栏和时间轴把四五个步骤挤在内容区上半部，也从不报告。

旧审美评分还给了生成器三个反向激励：

- 没有请求配图时，图片维度固定 85 分，文字页因此比真正有图的页面更容易通过。
- 节奏评分对只有一个标题轴的整册扣分，但单轴对齐本身是整册一致性的优点。
- 平衡评分把内容拉向几何中心，编辑式左右不对称的构图因此被当成缺陷。

这些分数既用于候选排序，也用于决定是否重编译页面。分数方向错了，生成器就会稳定地选择更空、更保守的版面。

## 决策

1. 新增 `src/core/design/page-fill.ts`，按页面采样已绘制内容的覆盖率，并判断是否存在视觉锚点。文字按墨迹框而不是文本框计算；覆盖超过半页的图形视为版面底色，不计入填充；页脚不参与计算。
2. 封面、章节页和引用页允许留白，不进入整册密度目标；其余页面取平均覆盖率和锚点比例。
3. 审美评分扩展为七个维度：层级、平衡、节奏、差异、配图、填充、视觉锚点。没有请求配图时，配图维度返回中性 55 分，而不是奖励性 85 分。
4. 节奏只惩罚真实重复，不再因为标题轴单一而扣分；平衡只惩罚内容质心漂到页面边缘或上下窄条，不再要求几何居中。
5. 内容页覆盖率低于 0.10 时，质量门输出 `SLIDE_UNDERFILLED:<页码>`。现有有界重编译循环据此只重做该页，而不是整册换皮。
6. 稀疏配方要用内容区的实际高度，而不是固定字号：过程栏和时间轴从正文尺寸起步，在放得下且不产生孤字的前提下收缩；索引页的稀疏正文允许到 36pt。
7. 单次生成的配图上限从 4 张提高到 6 张。提高上限只放宽“最多几张”，不强制每页配图，也不改变用户明确拒绝配图的意图。本项取代 ADR 0024 第 16 条中的 4 张上限；并发限制和“不变成相册”的目标不变。

## 后果

- 同一份内容在空页面和满页面之间会得到明显不同的分数，候选排序与页面重编译终于指向同一个目标。
- 质量门可能因为极空页面拒绝候选；这是有意的，失败仍不改变当前项目。
- 覆盖率是版面启发式，不是像素级设计评审。它不能判断配色、字体搭配或语义是否恰当，这些仍由视觉评审处理。
- 新增配方必须同时满足容量、无孤字和填充目标；只把元素放进内容区不再算完成。
