# 0095：批量版本买一次配图，所有版本共用

## 状态

已接受（2026-10-25）。修订 [ADR 0091](0091-batch-design-variants.md) 第 4 条（"批量只跑到设计为止"）：批量仍然不跑视觉复检，但配图不再留到选定之后。

## 背景

ADR 0091 让批量只跑到设计为止，理由是"配图与视觉复评最贵，为 8 个版本各付一次、然后丢掉 7 个，是把钱花在不会被看到的地方"。代价落在同一个地方：**画廊卡片和整册预览里没有图**。

真实反馈是"生成的 PPT 和市面上的好稿差很远"。拆开看，差距的一半不在排版：设计已经给页面留了配图位（右半页或右下角），预览不画图，那块地方就是白的；更糟的是没有图时选择逻辑会退回另一套配方，预览里的版面和最终稿根本不是同一个（见 ADR 0093 与预览占位块那次修复）。用户在拿一个残缺的渲染结果评判设计。

"8 版各买一次"的算法其实立不住：配图的提示词来自**内容阶段审核过的配图意图**，八个版本问的是同一张画；差异只在版面与配色。为同一张照片付八次钱是重复购买，不是成本。

## 决策

1. **整批只生成一套配图。** 配图计划用第一张卡的设计（`layout` 与角色在八个版本之间一致）加内容阶段的意图计算，然后按既有上限（整册最多 4 张）生成一次。图是内容资产，不是风格皮肤，八个版本共用是合理的。
2. **卡片与整册预览直接用这套图。** 有图的页画图，没图的页画占位块：图框始终存在，构图就是成品的构图。占位块规则见 `src/services/preview-placeholder.ts`。
3. **选定版本时复用，不重复购买。** `generateFromDraft` 的 `prepared` 增加 `visualAssets`；`planAssetTopUp` 只把批量**没有覆盖**的页排进生成队列，已覆盖的页直接沿用。同一张照片不会因为"保留这一版"再付一次钱。
4. **失败路径不变。** 图像服务没有凭据、超时、限流都只是少一张图：卡片与预览退回占位块，批量照常完成。视觉复检仍然留到选定之后。
5. **界面把这件事说清楚。** 画廊脚注改成"整册配图只生成一套，所有版本共用；选定后不再重复生成配图，只补缺图的页并跑完整质检"，整册预览标注"配图与成品一致（缺图页为占位块）"。

## 结果

- 画廊第一次展示的是"有照片的版面"，而不是半张白页；用户比较的是配色 × 骨架，而不是谁的留白更空。
- 批量的图像成本从 0 变成"整册一套"（≤4 张），而保留版本时的成本从"整册一套"降到"只补缺页"，两头相加与之前基本持平，甚至更省。
- 预览与成品的一致性再进一步：ADR 0093 修好了版面，这里补上了版面里最重要的那块内容。

## 未覆盖

- 配图角色按第一张卡的计划生成。若后续某张卡把同一页的图从 `side` 改成 `band`，复用的是同一张图，靠图框裁剪适配，比例不合时会切掉一部分画面。
- 整册预览会把 20 页的图全部解码一次，内存比无图时高；关闭对话框即释放，与之前的缩略图缓存策略一致。
- 批量仍不跑视觉复检与质量门，排版问题数是在无视觉评审的路径上测的。
- 图像服务未配置时没有任何提示：卡片安静地显示占位块。是否要在画廊里提示"未配置图像服务"，留给设置页的统一提示决定。
