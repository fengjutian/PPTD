# 0025：对比页的纵向节奏与字号阶梯

## 状态

已接受（2026-10-22）。

## 背景

一份 20 页的教学课件里，对比页（`comparison` 内容块）长成了这样：两张 5.3×1.7 in 的卡片，浮在 3.75 in 高的内容区上半部，卡片以下 3.26 in（整页 43%）连续留白；栏头 18pt、正文 16pt，两级只差 2pt，层级靠一条深色标题条硬撑；两条要点之间是一个空行，行距约 2.4 倍。

单个数字看都不算错：每张卡片都装得下自己的两行字，每个文本框都没有越界。问题出在**整页的分配**上——卡片的高度只由自己的两行字决定，页面的剩余空间没有参与决定；字号的阶梯也只由"装得下"决定，没有一条"栏头必须明显大于正文"的规则。

## 决策

1. `CONTENT_REGION` 是对比页几何的唯一来源，渲染器和容量评审读同一组数：
   - 列宽 47.5%，列间距 5%（两列正好铺满内容区左右边距）；
   - 栏头 22pt，要点 18pt，可读下限 14pt。
2. **面板有最小高度。** 面板至少占内容区高度的 55%，短内容不再缩成一条窄卡；内容多时面板继续按文字高度增长，上限是内容区。
3. **短块垂直居中。** 内容块的剩余空间按 `blockVerticalAnchor = 0.5` 分配，对比页、卡片网格、指标网格共用。原先的 0.30 把每一页短内容都推到内容区上三分之一。
4. **文字在面板里居中。** 栏头固定在面板顶部，要点在栏头以下的区域垂直居中，短栏不会把文字顶在栏头下面、在底部留一个洞。
5. 容量评审（`fitComparisonColumn`）改用同一组字号与列宽，审核界面提示的"要排到多少 pt 才排得下"就是渲染器实际会用的值。

## 结果

- 同一页：卡片高度 1.7 → 2.4 in，占页高 23% → 32%；底部连续留白 3.26 in → 约 2 in；栏头与要点 18/16 → 22/18。
- 短对比不再悬在页面上半部：两张卡片落在内容区中部，上下留白接近。
- 对比页、卡片网格、指标网格的短块使用同一个垂直基准，翻页时内容不会一页偏上一页偏下。

## 未覆盖

- 卡片网格的角标、编号栏、引文面板还有各自的版式参数，这一轮只统一了垂直基准，没有统一它们的字号阶梯。
- 页脚（章节、页码）仍然没有生成规则，模板没有画就没有。
- 模板装饰图形与文字框的碰撞检测没有做：装饰压到标题首字时，目前仍由模板自己负责。
