# 0042：Agent 工作流、整册总览与定点复检

## 背景

AI 内容生成、内容审核、设计生成、视觉评审、问题修复和导出此前由多个 UI 状态分别表达。视觉层已经能生成 Contact Sheet、按页缓存评审结论并增量渲染真实 PPTX，但这些能力没有作为结构化结果进入报告，用户无法确认整册评审是否运行，也看不到定点复检复用了多少页面。

主题预设也只有色板、字体、字阶和自然语言说明，Design Agent 缺少受众、推荐页面类型、密度、字体回退、图表色板和禁止组合等可验证元数据。

## 决定

1. 新增纯应用层 Agent 工作流状态机，显式表达检查、规划、内容生成、内容审核、设计生成、确定性质检、视觉评审、修复、待导出、导出、完成、取消和失败状态。状态机不进入 `PresentationDocument`，不会改变文档 revision 或撤销栈。
2. UI 的内容生成和设计生成使用同一工作流状态；非法阶段跳转以稳定错误码 `AGENT_WORKFLOW_INVALID_TRANSITION` 拒绝。
3. `DesignQualityStageResult` 返回最终采用轮次的 Contact Sheet、整册专用评审结论和逐页复检复用统计。报告必须区分整册结论和逐页结论。
4. 自动修复仍只允许修改视觉评审明确指出的页面。真实 PPTX 渲染仅重画设计变化页；逐页评审仅上传缺少当前签名结论的页面；最后一轮仍重新执行整册评审。
5. 主题预设元数据保存在独立的结构化注册表中，覆盖适用场景、受众、推荐页面类型、内容密度、字体回退、页面节奏、图片风格、图表色板和禁止组合。Design Agent 提示词和主题详情读取同一份元数据。

## 边界

- Contact Sheet 是评审输入和报告证据，不进入持久化文档，也不成为导出内容。
- 缓存只在一次质量阶段执行期间有效，并按渲染来源、页数和设计签名隔离。
- 逐页评分缺失时不得拆分批次结论，也不得将未检查页面记为已覆盖。
- 工作流状态不授权 Agent 修改内容；内容与设计权限仍由命令、Schema、revision 和内容指纹保证。
- 主题元数据是设计指导，不得覆盖用户已确认的内容或绕过布局容量检查。

## 验收

- 报告展示最终 Contact Sheet 以及一致性、重复控制和主题匹配分数。
- 只有一页变化时，下一轮逐页请求只上传该页，未变化页复用原结论；整册总览仍重新检查。
- UI 能显示当前 Agent 工作流阶段，取消和失败进入明确终态。
- 每个内置主题都有完整元数据，AI 提示词包含页面类型、密度、字体回退、图表色板和禁止组合。
