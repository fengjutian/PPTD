# 0067：时间线轨与引文页配方

## 状态

已接受（2026-10-24）。实施见 [TASK-DESIGN-006](../development/tasks/0016-timeline-and-quote-recipes.md)。

## 背景

到 ADR 0065 为止，内容块里只剩 `timeline` 和 `quote` 没有配方：

- 时间线页仍画成横向线 + 上下交错的小字，3–6 步时字被压得很小，页面下半部空；
- 引文页仍用一个大文本框 + 引号，长引文和短引文的字号、行宽没有统一；
- 这两类页面在模板页和预设页都走旧分支，整册的“叙事节奏”缺两个关键页型。

## 决策

### 1. `timeline-rail`：日期在左、事件在右的纵向时间轴

- 标题、短线走 `PageChrome`；`showRule` 决定是否重复模板表头线；
- 左侧 0.16 页宽放时间/期间标签，右对齐；轨道在 0.18 处；右侧 0.03 后是事件说明；
- 每条时间线：小圆点落在轨道上，标签 16pt 粗体，说明 16pt；
- 行高由标签和说明的测量高度决定，步距 12–28pt；整组在内容区内垂直居中；
- 3–6 条；超过返回 conflict 回退旧分支；
- 允许模板底图，`showRule=false`，颜色由命令层回退。

### 2. `quote-field`：大引文 + 引号 + 署名

- 标题作为小 kicker（24pt），短线按 `showRule`；
- 内容区左侧 0.02 宽 accent 竖线；大引号 72pt 作为版面锚点；
- 引文正文 32–40pt，行宽不超过内容区的 0.72；按测量高度垂直居中；
- 署名 16pt 放在引文下方；引文过长时先缩到 24pt，仍放不下返回 conflict；
- 仅用于 `layout === "quote"` 且存在 quote 块；带多条目列表的 pull quote 页继续走 `editorial-index` / `comparison`。

### 3. 共同规则

- 只读内容；`consumed.blockIds` 包含 timeline/quote 块 ID；命令层 `consumptionProblem` 守卫。
- 模板页只追加内容元素，背景/Logo/装饰/页脚不变。
- 不新增文案；“VS”式装饰不适用于这两个配方。
- 旧设计无 recipe 时仍走旧分支。

## 边界

- 不改变内容/设计隔离、revision、审核状态。
- 模型只选配方，不输出坐标/字号。
- 时间线不做分页；引文不做多引文轮播。
- 模板封面/章节页不接入。

## 结果

- 时间线页从横向小字变成日期/轨道/事件三段式纵向结构，3–6 条都能读。
- 引文页的字号和行宽由内容测量决定，不再是“一个框里塞一段话”。
- 模板页和预设页共用同一套时间线/引文构图。
- 内容块里的 `timeline` / `quote` 都有可渲染落点，配方覆盖表基本完整。

## 未覆盖

- 超过 6 条时间线的分页/分组。
- 多引文、引文配图、引文作者头像。
- 章节页（`section`）的专门配方。
- 表格页继续使用原生表格，不走配方。
