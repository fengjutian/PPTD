# 0033：主题预设库从 4 套扩到 10 套

## 状态

已接受（2026-10-22）。

## 背景

ADR 0031 先落了四套预设（纸墨、青编、藏青、素纸），覆盖人文、通用、商务、叙事四种气质。但同一套生成规则要拉开风格差异，最便宜的办法是补主题资产，而不是继续调版式代码。四套预设只覆盖了少数场景。

## 决策

新增六套，全部复用同一 `ThemePreset` 结构（色板 + 字体配对 + 字阶 + 标题字距）：

| id              | 名称   | 气质                       | 强调色    |
| --------------- | ------ | -------------------------- | --------- |
| tech-blue       | 科技蓝 | 冷白、深蓝、黑体紧排       | `#2563EB` |
| finance-gold    | 金融金 | 白底、墨黑、哑金、宋体标题 | `#A67C2E` |
| medical-teal    | 医疗青 | 浅青白、深青、黑体         | `#0E8C7F` |
| gov-red         | 政务红 | 白底、朱红、宋体标题       | `#A62B1F` |
| creative-orange | 创意橙 | 暖白、橙红、字号跳跃       | `#E0662A` |
| education-green | 教育绿 | 浅草白、墨绿、宋体标题     | `#3E7C44` |

同时扩展 `inferThemePresetId`：金融/医疗/政务/科技/创意/培训各自映射到对应预设；原有教学→纸墨、汇报→藏青、展陈→素纸不变。推断只是推荐按钮的依据，不自动覆盖模板。

## 结果

- 预设从 4 套增加到 10 套；选择器与推断逻辑自动列出新预设。
- 推断测试覆盖 9 个场景 + 未知主题回落默认。
- 每套预设仍然只表达"视觉系统"：用户显式选择时才覆盖模板的强调色、字体、字阶与标题字距。

## 未覆盖

- 预设之间只保证"气质不同"，没有做视觉回归基线；新增预设的观感仍靠人工抽查。
- 还没有按行业自动选预设（推断仅用于推荐按钮）。
- 每套预设只有四个色板槽位，复杂模板（多强调色、深色页）仍可能需要更多槽位。
