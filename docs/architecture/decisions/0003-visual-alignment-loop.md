# 0003：视觉目标与有界视觉对齐循环

## 状态

已接受。

## 背景

仅根据内容和模板元数据一次性生成设计，无法可靠判断页面的视觉重心、层级、背景冲突及跨页一致性。仅增加固定坐标规则也只能保证几何整齐，不能证明视觉质量合格。

## 决策

PPTD 使用厂商无关的 `PresentationVisualGoal` 定义整套演示的风格、情绪、密度、对齐方式、背景节奏和最低质量分数。设计生成必须接收该目标。

视觉优化采用有界闭环：

1. 从不可变文档快照渲染单页图和整套缩略图。
2. 通过支持图片输入的视觉模型生成结构化 `VisualReview`。
3. 只修复报告中受影响的设计属性和页面。
4. 每轮验证审核内容指纹未变化。
5. 达到目标、连续提升低于 3 分或完成 3 轮时停止。

视觉模型只负责评价和修复意图，不直接覆盖 Content Model，也不直接输出任意坐标。坐标仍由确定性排版引擎计算和验证。

## 降级行为

当前 AI 提供商或模型不支持图片输入时，不得宣称执行了视觉评审。系统只能报告“结构与确定性布局校验”，并跳过视觉循环。未来的视觉模型通过独立端口接入，不得把厂商名称写入领域模型或服务文件名。

降级不得阻断 PPT 生成：视觉评审、像素对比度检查和确定性质量门的失败一律降级并记录原因，文档照常产出。详见 [`0015-visual-qa-failure-must-not-block-generation.md`](0015-visual-qa-failure-must-not-block-generation.md)。

## 结果

- 视觉质量拥有明确目标、评分和停止条件。
- 失败与停滞可诊断，不会无限消耗模型调用。
- 视觉修复无法静默修改已审核内容。
- 是否完成视觉验收由真实图片模型能力决定，而不是提示词声明。
