# 0069：内容页的排版层级

## 状态

已接受（2026-10-24）。实施见 [TASK-DESIGN-009](../development/tasks/0019-content-page-typography.md)。

## 背景

真实页面暴露的不是“没有配方”，而是**配方之外的内容页**：

- 卡片正文从 18pt 一路长到 26pt，四个要点像海报；
- 每条要点同权，读者先看到四团字，而不是“主语 + 判断”；
- 30 字以上的标题仍按 display 字号排，换成两行后压住页面；
- 编辑器默认打开网格，新页面先像方格纸，用户还没看设计就先被辅助线干扰。

## 决策

### 1. 卡片正文封顶

两栏卡片正文最大 20pt；短而稀疏的卡片最大 22pt。字不够放时继续缩，不靠放大填满卡片。

### 2. 项目符号降为标点

项目符号字号 = 正文的 60%，限制在 10–14pt。它不再和正文争夺注意力。

### 3. 主谓分层，不改文案

对“主语 + 判断”的中文要点，在自然断点（可能/将/仍/决定/需要/是/释放/提升/降低……或首个逗号）前加粗主语，后半句保持常规字重。加粗通过 `TextRun` 的字符范围表达，`text` 仍是审核原文，导出仍是原生文本。

### 4. 长标题降级

加粗文本超过 24 字，字号封顶 34pt；超过 36 字，封顶 30pt。标题不再一路长到框满。

### 5. 网格默认关闭

画布网格是编辑辅助，不是幻灯片内容；默认关闭，用户需要时再打开。

## 边界

- 不新增、不删改、不重排内容；`runs` 只覆盖已有字符。
- 没有自然主谓断点的要点保持单一字重，不硬猜。
- 模板底图、卡片形状、Logo、页脚不变。
- 字号封顶只影响排版，不影响内容版本和审核状态。

## 结果

- 同样的四要点页从“四团大字”变成“主语加粗 + 判断句”，卡片内有了第一层阅读顺序。
- 26pt 卡片正文和 26pt 项目符号消失，卡片不再像海报。
- 长标题不再压住内容区。
- 编辑器默认不再把网格画在幻灯片上。

## 未覆盖

- 模板卡片是固定 artwork 时，页面下半部仍由模板几何决定；接管模板内容区的方案见 [ADR 0070](0070-design-plan-compiler.md)。
- 英文要点的断点规则仍以中文虚词为主，英文长句多数保持统一字重。
- 对比页、指标页的垂直填充仍需单独调整。
- 真实模型样张尚未用于校准这些阈值。
