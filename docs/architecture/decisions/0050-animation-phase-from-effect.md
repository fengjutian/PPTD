# 0050 动画阶段由效果派生

## 状态

已接受（V0.2）

## 背景

TRS 4.4.5 要求九种动画效果，分属进入、强调和退出三个阶段，并允许复制动画。此前的模型只有出现、淡化、飞入三种效果，`phase` 固定为字面量 `"entrance"`。

如果让 UI 同时选择效果和阶段，就会出现“消失 + 进入”“脉冲 + 进入”这类无效组合；Schema 允许、预览和未来的 PPTX 导出却不知道该怎么处理。

## 决策

### 效果决定阶段

新增 `phaseForEffect(effect)`：

- 出现、淡化、飞入、浮入、劈裂、擦除、缩放 → `entrance`。
- 强调脉冲 → `emphasis`。
- 消失 → `exit`。

`add-animation` 不接受阶段参数，由命令派生；`set-animation` 改变效果时重新派生。动画窗格用同一张表显示阶段，不需要第二份映射。

### Schema 拒绝矛盾状态

`SlideAnimation.phase` 扩为三值枚举，文档校验时检查 `phase === phaseForEffect(effect)`，不一致报 `ANIMATION_PHASE_MISMATCH`。

这样即使外部文件或旧版本工具写入了矛盾记录，也不会悄悄进入当前文档；迁移只处理版本，不替用户猜阶段。

### 版本 16 只扩枚举

`15 → 16` 迁移只改 `schemaVersion`：旧动画的阶段都是 `entrance`，新枚举仍接受；没有时间线的文稿保持没有时间线。固定样例 `v16-document.json` 覆盖强调阶段。

### 复制动画是独立命令

`duplicate-animation` 复制源动画（新 id、相同元素/效果/计时/开始方式/方向），插入到源动画之后。一次撤销；锁定对象拒绝。

没有复用 `add-animation`：那会把副本追加到时间线末尾，用户还要再排序一次，而“复制并保持顺序”是一个意图。

### 预览是 UI 状态

九种效果通过 `animation-${effect}` 类和 CSS 关键帧在画布预览。预览不进入文档、revision 或撤销栈，也不代表 PowerPoint 的真实时间线。

## 后果

- 无效的效果/阶段组合在命令和 Schema 两层都被挡住。
- 增加新效果时只需扩展 `phaseForEffect`、枚举和预览 CSS，UI 的效果列表从同一份配置生成。
- PPTX 原生动画已对出现、淡化、飞入、擦除和缩放实现（[0057](0057-native-animation-export.md)）；其余四种仍只预览，导出报告逐页说明未写入。
- 方向参数仍只对飞入有意义，其他效果的方向固定。

## 备选方案

- **UI 自由选择效果和阶段**：会产生无法解释的组合，且预览/导出没有对应语义。
- **把阶段存成冗余字段但不校验**：迁移或手写文件会留下矛盾记录，窗格和未来的导出器各信一个字段。
- **用 add-animation 追加实现复制**：顺序不对，还要额外排序命令，破坏“一次意图一个事务”。
