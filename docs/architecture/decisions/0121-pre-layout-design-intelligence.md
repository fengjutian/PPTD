# ADR 0121：生成前设计智能进入逐页设计合同

## 状态

已接受。

## 背景

逐页设计过去只收到 SlideBrief、模板分析、整册方向和配方目录。模型能够选择合法配方，却需要自行重复推断内容关系、整册节奏和模板品牌语法；本地设计记忆也只影响方向提案，没有进入最终逐页设计。这会产生连续页面同构、仅换主题色以及品牌轴线漂移。

## 决策

在调用逐页设计模型前，由前端服务层生成 `DesignIntelligence`：

- 从已审核内容块和 SlideBrief 判断 statement、comparison、chronology、process、evidence、hierarchy、quotation、scene 等关系。
- 为每页指定 opening、build、evidence、turn、pause、close 等整册节奏角色。
- 给出与关系匹配的优先布局家族，并把相邻页的首选家族列入避免集合。
- 从模板测得标题轴、正文栏数、图像版式数量、色板和字体，形成只读品牌语法。
- 用户开启设计记忆时，将最近外观指纹和用户明确记录的偏好一起送入逐页设计请求。

Rust AI 适配器只负责校验大小并将结构化上下文写入提示词。它不得从这些数据改写标题、正文、数字、引用、备注或页面顺序。

## 后果

- 第一次生成即可按语义关系和整册节奏选择构图，减少事后修复成本。
- 品牌规则来自真实模板测量，而不是模型猜测。
- 设计记忆仍是可关闭的本地能力，只影响设计，不进入内容模型。
- 后续新增布局家族或审美维度时，应扩展结构化设计智能，不在提示词中加入不可验证的自由文本规则。
