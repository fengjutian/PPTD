# 0061：论证形式规则与双栏版式

## 状态

已接受（2026-10-23）。

## 背景

一份生成的百度年报解读里，第 9 页标题是"组织架构调整与资源倾斜显示 AI 业务优先级已高于传统搜索"，页面是两张白卡片：左三条、右两条，全部在说"组织在向 AI 倾斜"。没有数字、没有时间点、没有对比基线，标题的结论在页面上找不到任何证据。

这不是排版错误，而是两条独立的链路各缺一段：

1. **生成端只约束篇幅，不约束论证形式。** 提示要求"每页 2–5 条短要点、每条不超过 45 字"，模型手里只有一段主题、又没有事实可引，于是默认用 `bullet-list` 把每页压成同一个形状。"变化"被写成并列要点，"对比"没有两侧，"流程"没有先后。
2. **双栏渲染把要点拼成一整段。** 每条要点是 `• 文本` 拼成的字符串，两栏各自在面板里垂直居中；换行回到行首，悬挂缩进失效，两栏首行也不在同一水平线上。面板高度按内容区的 60% 封顶，卡片浮在页面中间。

质量门只量越界、重叠、对比度和溢出；视觉评审被明确要求"不评价内容观点是否正确"。所以"这页什么都没证明"永远不会出现在报告里。

## 决策

### 1. 论证形式进入共享词表

`assets/content-lexicon.json` 新增 `argumentRules`：`forms`（变化、对比、流程、指标、并列、判断，每种对应一个内容块和一组判定词）与 `vagueIntensifiers`（只有程度、没有事实的词）。Rust 用它写生成提示，前端用同一份做审核提示。两边读同一份文件，规则不会在提示与检测之间漂移。

### 2. 生成端先定形式，再选内容块

`draft`、`slides_batch`、`rewrite_slide` 三个提示加入 `argument_rules_prompt()`：

- 变化 / 趋势 → `comparison`（前 → 后两栏）或 `timeline`，**不得**写成 `bullet-list`；
- 对比 / 选型 → `comparison`；
- 步骤 / 流程 → `process`；
- 指标 / 构成 → `metric`（仅当确有数字）或 `table-data`；
- 并列维度 → `bullet-list`，每条一个维度，任意两条互换位置后读者读到的东西应当不同；
- 单一判断 → `paragraph`。

另加两条生成纪律：每条要点要么带数字、时间、主体或具体动作，要么明确写成判断，不能用"明显、逐步"这类程度词冒充事实；写完把要点顺序打乱自检，读起来没有区别就合并。

### 3. 审核页报告论证缺口（不阻塞）

`src/core/content/argument-quality.ts` 的 `assessArgument` 检查两件事：

- 标题或要点里命中两个以上变化词、又没有 `comparison` / `timeline` / `process` 块 → warning："这一页在讲变化，却写成了 N 条并列要点"；
- 所有要点都没有数字、年份、单位或出处 → info："要点里没有可核对的事实"。

结果挂在 `assessLayoutCapacity` 的 `items` 作用域上，和容量提示一起显示在内容审核页。它只提示，不改已审核内容，也不阻塞确认。携带结构化块的页面由块决定形式，不参与这项检查。

### 4. 双栏版式重写

- **每条要点一个文本框，标记单独占 0.022 的槽。** 悬挂缩进成立，导出的 PPTX 里每个要点也是独立可编辑对象。
- **两栏共享字号与首行基线。** 字号从 26pt 向下取"内容区装得下"的最大值，不再固定 18pt 让文字缩在卡片上半部。
- **切分点按两栏高度均衡选择**，不再固定 `ceil(n/2)`：五条不同长度的要点会得到 2+3 而不是 3+2。
- **面板顶部对齐、各自按内容取高**，不再按内容区 60% 封顶，也不再画一根比卡片更高的中缝装饰线。

## 结果

同一页（5 条要点、深色模板、13.33 × 7.5 in），导出后用 PowerPoint 渲染：

- 正文字号 18 → 22pt，两栏从 3+2 变为按高度均衡的 2+3；
- 两栏首行落在同一水平线，换行文字保持悬挂缩进；
- 卡片贴住内容区（约 0.30–0.83 页高），上下留白接近，不再浮在页面中部。

## 未覆盖

- 模型仍然没有事实来源。没有素材时，提示只能要求它把判断写清楚，不能变出证据；真正的补数据仍要靠用户。
- 视觉评审仍然只评设计、不评论证。论证缺口由确定性的 `assessArgument` 报，不交给视觉模型打分。
- 模板自带的双栏安全区仍以 `templateColumnSize` 为起点（上限 26pt），模板与新版式的字号策略如何配合，属于后续模板适配工作。
