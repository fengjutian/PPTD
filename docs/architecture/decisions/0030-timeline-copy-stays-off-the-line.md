# 0030：时间线的文案不跨过时间轴

## 状态

已接受（2026-10-22）。

## 背景

时间线页（第 19 页）的文字压在线上：上方条目的说明从线上方一直画到线下方，盖住时间轴和圆点；下方条目的标签与说明互相重叠。

原因不是修复，是版式本身：标签和说明的框按"内容区高度的百分比"定位（上方 −0.18h、下方 +0.23h），框高 0.22h，比留给它的空间还高，于是框跨过了线。说明本来只需要一两行，却拿到一个两行高的固定框，文字从框顶开始画。

## 决策

1. 时间线上的每个条目按"线 + 间隙"排版，而不是按内容区百分比：
   - 上方：说明底边停在线上方 0.03，标签在说明上方；
   - 下方：标签从线下 0.03 开始，说明在标签下方。
2. 框高按字号算（标签 15pt、说明 13pt×2 行），不再用内容区比例。
3. 首尾条目的框夹在内容区左右边界内，长标签不会跑出页面。

## 结果

- 时间线的标签与说明各在线的两侧，不再盖住线、圆点或彼此。
- 新增 1 条测试：时间线上除标题外的所有文字框，要么整体在线上方，要么整体在线下方。

## 未覆盖

- 条目超过 6 个时，圆点间距变小，标签宽度仍然按固定比例分配，长标签会缩到 10pt。
- 时间线没有"上下交替"之外的排法；所有条目都在同一侧时没有专门优化。
