# 0094：两个方向自有构图——纸本专栏与数据仪表

## 状态

已接受（2026-10-25）。补上 [ADR 0087](0087-four-renderable-directions.md) 的"未覆盖"一节承认的缺口，并让 [ADR 0093](0093-variant-batch-palette-times-skeleton.md) 的"配色 × 骨架"真正落到页面构图上。

## 背景

ADR 0087 建立了四个可渲染方向，也写明代价：`paper` 与 `instrument` 只改变版心、标题轴、字阶与竖线，**不新增页面配方**，四个方向共用同一套 12 个配方。ADR 0093 让批量版本按"配色 × 骨架"配对之后，六张卡的版心、标题轴和竖线确实不同了，但正文页仍然画同一个东西：

- `paper` 的"纸本专栏"在正文页上还是编号栏（01/02/03 + 行间细线），只是版心窄一点；
- `instrument` 的"数据仪表"在正文页上还是编号栏，只是左边多一条竖线。

也就是说，方向名字承诺的是构图，页面给出的仍是同一套排版。方向门（ADR 0087）和批量版本（ADR 0093）都在卖"四种版面"，而四种版面里只有封面、章节页和结构化块页真的不同。

## 决策

### 1. 两个方向各自拥有一条配方

新增 `paper-column` 与 `instrument-columns`，只属于对应方向：

- `paper-column`（[paper-column.ts](../../../src/core/layout/recipes/paper-column.ts)）：一个被测量的正文栏。标题降一档（编辑式的 0.82），标题下是一条**通栏发丝线**而不是编辑式的短强调线；2–6 条内容各自成段，1.55 倍行距，段间距 18–26pt 有界；没有编号、没有行间分隔线、没有强调色数字。它读起来像书页，而不是扫描用的清单。
- `instrument-columns`（[instrument-columns.ts](../../../src/core/layout/recipes/instrument-columns.ts)）：2–4 条内容各占一格。每格从上到下是发丝线刻度、超大编号（按可用高度缩放，38–72pt）、要点正文；格与格之间是发丝竖线，整块下方用一条收口细线把它关成一个面板。编号就是作者写下的顺序，不是新增的装饰；正文尺寸全格统一，按最长的一格测量。

### 2. 选择权在命令层，不在模型

方向自有配方由概念决定：`supportedDirectionRecipe`（[plan.ts](../../../src/core/layout/recipes/plan.ts)）在"共享列表"之前被两处选择逻辑调用——`chooseRecipeId` 与设计计划编译器 `planRecipe`。因此：

- 模型不需要、也不会被提示这两个配方；Rust 侧的设计提示词保持 12 个配方不变；
- 两个配方被加入 TypeScript 的配方枚举（`RecipeId` 与 `aiDesignRecipeIds`），让"已实现配方"只有一个定义，类型与渲染器不再各说各话；
- 模型若在别的方向上点名它们，会被概念的配方集合拒绝，按既有规则回退。

### 3. 装不下就退回共享列表

方向自有配方自己判断适配性，不强行套用：结构化块（表格、图表、指标、对比、流程、时间线）、模板页、有底图的页面、封面/章节/引文页一律不接；`instrument-columns` 只收 4 条以内且单条不超过 30 字，`paper-column` 只收 2–6 条。不满足时 `supports` 返回 false，选择逻辑落回 `editorial-index` / `asymmetric-split`，页面不会因为方向而变空。

## 结果

- 同一份内容在四个方向下得到四种构图：编号栏（编辑式）、更宽的同构编号栏（纪实全幅，差异来自图像）、正文专栏（纸本）、仪表面板（数据仪表）。
- 批量版本的十二张卡不再只是色号差异；方向门和整册预览看到的就是最终稿会画的页面。
- 不增加模型调用：两条配方由代码选择，每个版本仍只付一次设计请求。
- 多页节奏仍然有效：`planDeckRecipes` 的"连续三页同配方"规则只看共享列表，方向自有配方在同一册里重复出现时不触发替换（它本来就是该方向的页面语言）。

## 未覆盖

- **纪实全幅仍没有自己的构图。** 它的差异来自图片（主视觉、通栏、侧栏），而批量版本不生成配图，所以它在画廊里看起来最接近编辑式。真正的下一步是"整幅图 + 压边标题"的图文页，需要先有素材。
- 表格、图表、指标页仍走共享配方：这两种方向目前只接管纯文字与短要点页。
- 两个配方不对模板页生效（模板自带版式），所以模板模式下的四方向差异仍然是零——与 ADR 0087 一致。
- 方向自有配方的数量随方向增长时会走"每个方向一条"的路子；如果将来一个方向需要多条自有配方，选择规则需要从"motif → 一条配方"改成"motif → 一组按内容挑选的配方"。

## 验证

- `src/core/layout/recipes/recipes.test.ts`：两条配方的标题/正文/条目消费、无编号、单一文本轴、每格一列、收口细线；不满足容量时 `supports` 为 false。
- `src/core/layout/recipes/plan.test.ts`：同一页内容在三个方向分别选中 `editorial-index` / `paper-column` / `instrument-columns`，5 条内容时仪表方向退回共享列表。
- `src/core/layout/design-compiler.test.ts`：设计计划路径下方向自有配方优先于 role 表。
- `tools/design-preview/design-preview.test.ts`：十页夹具在四个方向下正文列数、编号数量不同；`lintTaste` 四个方向均无告警。
- 全量 Vitest、TypeScript、ESLint、Prettier、生产构建通过；四个方向的页面另行用真实 PPTX + LibreOffice 渲染核对。
