# 0104 图表配色：填充不是墨色，网格是页面的一部分

## 状态

已接受（2026-10-26）。

## 背景

图表页一直没有进入任何目视基线：十页夹具全是白底、且没有图表页，图表的导出参数只在单测里被检查过"字段写进去了"。把一页图表加进深色夹具后，两个缺陷立刻暴露：

1. **柱子是纯白的。** `data-story` 用 `ctx.colors.accent` 作为系列色；在深色页上 `accent` 是**墨色**——ADR 0098 已经写明它是"这一页上画记号的墨"，深色页上是近白色。把它当填充，柱子就成了白色矩形，和 Office 默认图表撞脸。
2. **网格线是硬编码的 `#E3E7EC`。** 浅色页上没问题，深色页上是一道亮白的梯子，比数据还显眼。

共同点是：**把"墨"与"面"混用了**。0098 把这两件事分开（`accent` 是墨、`accentStrong` / `panel` 是面），图表这条路径没有跟上。

## 决策

### 1. 系列色从品牌色派生，不从墨派生

`chartSeriesColors(colors, count)`：

- 背景是浅色：系列色 = `accentStrong`（品牌实心色）。
- 背景是深色：系列色 = `mixHex(accentStrong, white, 0.45)`，即把品牌色**提亮**到在深色底上可读，而不是把墨提亮（那只会更白）。
- 第二、第三系列在没有 `accent2/3` 时，由基色向背景混合得到，保证同一页内的系列可区分。
- 第一版实现用的就是 `accent`，渲染出来仍是白柱——**根因是基准选错了，不是提亮比例**。这条写在这里，避免下次再选墨。

### 2. 网格线跟随页面

`chartGridColor(background)`：深色页向白 14%，浅色页向黑 8%。网格是"提示"，不是"表格线"。

### 3. 图表仍必须是原生对象

系列色写进 `chartColors`，网格写进 `valGridLine`，都由 PptxGenJS 生成原生图表。没有降级为图片的路径。

## 后果

正面：

- 深色页的柱状图从"白条柱"变成品牌色系，网格退到背景里。
- 图表配色与整册设计同源，换主题即换图表。
- 深色图表页进入视觉夹具（`buildVocabularyPreviewDocument` 第 4 页），这类问题以后会被渲染检查到。

代价与限制：

- 只覆盖系列色与网格色。轴标签色仍取 `element.style.textColor`（配方给的是正文墨），没有单独的图表文字令牌。
- 多系列调色板的第 2、3 色是混出来的，不是设计选定的；真正多系列的版面还需要主题级序列色。
- `chartPaletteReadable()` 目前只有单测，没有接进导出报告。

## 验证

- `chart-theme.test.ts`：深色页系列色不等于墨色、对底对比度 > 2；浅色页等于 `accentStrong`；网格对底对比度 < 1.4/1.6；请求 5 个系列时仍能填满且互不相同。
- `design-preview.test.ts`：导出的 `ppt/charts/chartN.xml` 里出现派生色，且**不出现**近白墨色 `F2F6FA`。
- 真实渲染（PowerPoint）：深色页柱状图柱子为浅青、网格几乎不可见、数值标签可读。

## 备选方案

- **继续用 `accent` 作系列色**：深色页必然白柱，已证伪。
- **给浅色/深色各写死一套图表色**：与主题脱钩，换预设不生效；不采用。
- **去掉网格线**：深色页上更好看，但浅色页失去读数辅助；改为"跟随页面的弱网格"。
