# ADR 0112：Token 用量统计持久化

- 状态：已采纳
- 日期：2026-10-26

## 背景

Token 用量原先只保存在 Rust 进程内存中。应用重启会清零，无法反映累计模型用量，也容易让统计页看起来一直为空。

## 决策

在应用级 SQLite 数据库 `pptd.sqlite3` 中新增单行 `token_usage` 表，累计保存成功模型请求数、返回用量的请求数、输入 Token、输出 Token 和总 Token。

应用启动时在数据库迁移完成后加载累计值。每次成功请求完成时同步更新数据库；服务商未报告 `usage` 的流式请求只累计请求数。用户执行“清除统计”时同时清除内存与数据库数据，持久化失败则恢复原内存值并返回错误。

统计属于应用级诊断数据，不进入项目文件，不记录提示词、模型输出、API Key 或其他用户正文。

## 结果

- 应用重启和升级后保留累计统计。
- schema 版本从 3 升至 4，旧数据库自动创建统计表及初始零值行。
- 已有历史请求无法追溯，因此升级后的初始值为零。
