# 0087 四套可渲染方向与一次四点提案

## 状态

已接受（2026-10-25）。取代 [ADR 0075](0075-design-direction-proposal-and-selection.md) 中“固定两个方向”的数量与预设上限；其余事务、指纹、跳过与回退规则继续有效。

## 背景

方向门最初只有 `editorial` 与 `documentary` 两个可渲染预设，因此一次只提出两个方向，用户想看更多只能点“换一组”。实际使用中，两个方向不足以覆盖“文字判断、图片叙事、长文阅读、数据结论”这四类常见内容；而“换一组”每轮都要重新提案并重渲染，等待成本比一次多给两个方向更高。

单纯把同一骨架换图片策略或字号凑成四张卡，会让用户以为自己在选四种版面，实际只有两种，违反 [TRS FR-D1](../../requirements/PPTD-Design-Direction-TRS-v0.1.md) 对“不能是同一骨架换色”的要求。因此方向数量必须跟着可渲染骨架数量一起增长。

## 决策

### 1. 四个可渲染预设

`ConceptPresetId` 从两个扩为四个：

| preset        | 骨架                                           | surface      | 图像策略                  | 字阶     |
| ------------- | ---------------------------------------------- | ------------ | ------------------------- | -------- |
| `editorial`   | 编辑式：细线、编号栏、左轴，7% 页边距          | `rules`      | none / side / band / hero | strong   |
| `documentary` | 纪实全幅：图片占页，4% 页边距，不画标题强调线  | `full-bleed` | hero / band / side        | calm     |
| `paper`       | 纸本专栏：正文收进居中窄栏，标题轴内移         | `column`     | none / side / hero        | calm     |
| `instrument`  | 数据仪表：内容右移，左侧竖栏与细线，数字大字阶 | `rail`       | none / band / hero        | dramatic |

两个新 surface 的真实几何：

- `column`：`x 0.17 / y 0.10 / width 0.66 / height 0.80`，标题、强调线与正文一起内移，页面读起来像纸面专栏。
- `rail`：`x 0.22 / y 0.085 / width 0.72 / height 0.845`，命令层在 `x = title.x - 0.035` 画一条由标题顶到内容底的强调色细线；模板页不画。

封面标题宽度在右侧色块前收住（`ACCENT_PANEL.x - 0.03`）：窄栏与右移版心会把标题轴推向右，不能靠压住色块来换取宽度。四个预设共用同一套 12 个页面配方。差异来自 surface、字阶对比与图像角色，而不是复制一套页面绘制代码；模板页仍由模板占位符决定几何，surface 不覆盖模板。

### 2. 一次提出四个方向

`generate_deck_directions` 一次返回恰好 4 个方向，`preset` 必须分别覆盖四个可渲染预设且不重复。少一个、重复一个或出现未知预设都使整次提案失败，方向门回退单方向路径，不展示三张或两张“残缺”的卡。

预览仍是每个方向 2 页（封面 + 一页代表性正文），所以一次方向门最多：

- 1 次提案调用；
- 4 次单方向两页设计调用（每个方向一次）；
- 8 页本地渲染。

“换一组”仍最多 2 次；最坏情况是 3 轮提案 + 12 次两页设计。没有整册重跑预算。

### 3. UI

`DesignDirectionDialog` 固定展示 4 张卡，2×2 网格；每张卡仍是原生 `<button>`，预览图 alt 为“方向名 第 N 页预览”。“换一组（n/2）”与“跳过，按推荐方向生成”不变；卡片标题使用代码里的预设标签，模型只负责方向名、一句话立意和理由。

## 后果

正面：

- 用户第一次就能在“文字、图片、长文、数据”四种骨架之间比较，不必为了看第三种方向先接受一轮重新生成。
- 四个方向都走同一条命令路径，预览能画、最终稿也能画。
- 预设目录、模型合同与持久化枚举重新对齐；`paper` / `instrument` 不再是文档里存在但不可用的名字。

代价与限制：

- 方向门从 2 次两页设计增加到 4 次，提案与预览阶段耗时和调用成本约翻倍；失败回退时四个方向全部丢弃，只走单方向。
- `paper` 与 `instrument` 目前只改变 surface、字阶与图像角色，不新增页面配方；它们与 `editorial` 的差异是版心、标题轴、竖线与字阶，不是新的页面构图。
- 一次方向门要求 4 个候选全部渲染成功；任一预览失败都会回到单方向路径，这是“四个推荐”的严格代价。
- 模板模式仍不进入方向门：模板已经决定版式，四个方向只会把同一套模板预览四次。

## 备选方案

- **同一骨架 × 两种图像/字阶凑四张卡**：改动最小，但两张卡共用骨架，用户的选择被夸大；不采用。
- **三个方向，第四个放进“换一组”**：仍然要用户多点一次，且第三个预设与第四个预设的成本没有本质差别；不采用。
- **生成四套完整整册再让用户选**：成本约为整册的四倍，且用户要在四个长文档里找差异；不采用。
- **只加预设不加渲染差异（仅改枚举）**：违反“没有渲染实现的预设不得进入枚举”；不采用。
