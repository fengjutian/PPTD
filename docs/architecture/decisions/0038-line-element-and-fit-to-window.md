# 0038：线条是独立元素类型，适应窗口按容器实算

## 状态

已接受（2026-10-22）。

## 背景

M2 要求的编辑器能力里还差三样：线条、复制粘贴、适应窗口。

前两样在实现上都有真实的岔路口，第三样看似只是一行代码，实际是"假功能"。

### 线条：做成"很扁的矩形"还是独立类型

最省事的做法是把线条当成矩形：高度给 1 像素，填充设为透明。看起来能画出一条线，但代价是：

- 箭头端点没有地方放——矩形的样式里只有填充、描边、圆角；
- 虚线没有地方放；
- 导出只能写成一个扁矩形。PowerPoint 里那不是线，是一个几乎没有高度的对象，用户拖不动、改不了形状；
- 缩放时高度会变，线会粗细不一。

所以线条必须有自己的元素类型和样式。

### 适应窗口：写死 100% 是"假功能"

原来的按钮是 `setZoom(1)`——不管窗口多大，点一下都是 100%。这在 13 寸屏上凑巧能用，在 4K 屏上画布只有中间一小块，在窄窗口上则直接放不下。

## 决策

### 线条是独立的元素类型

1. `src/core/document-model/types.ts` 新增 `LineElement`：`type: "line"`、一个 `direction`（`horizontal` / `vertical` / `diagonal`）、一份 `LineElementStyle`（描边色、线宽、起点箭头、终点箭头、是否虚线）。
2. **线条不是矩形的子类**，它有自己独立的样式。矩形的 `fill` 和 `radiusPt` 对线条没有意义，箭头和虚线对矩形也没有意义。
3. Schema 版本从 10 升到 11，新增 `v10-document.json` 固定样例和迁移。迁移是恒等的：一个 v10 文档没有线条，升级后每页每个对象都还在，只是没有多画任何东西。
4. 新增命令 `add-line` / `set-line-style` / `set-line-direction`，域分类是 `design`——线条是纯视觉对象，不进内容哈希。

### 画布上的线条用 SVG 画

5. `src/features/editor/LineView.tsx`：用 SVG 而不是带边框的 div。箭���和虚线都是线条自己的属性，用 div 得靠伪元素硬凑，箭头还会被 `overflow: hidden` 裁掉。
6. 线条只有几个像素宽，按不中。SVG 里画**两条**线：一条正常宽度的可见线，一条加宽的透明描边作为命中区。用户不用精确对准那一像素就能选中它。
7. 缩略图和画布用同一个 `SlideElementContent`，所以缩略图里的线条和画布上的一致。

### 导出为原生线条

8. `export-pptx.ts` 把线条写成 `pptx.ShapeType.line`，并把箭头（`beginArrowType` / `endArrowType`）和虚线（`dashType`）写进 XML。**不导出成扁矩形，也不导出成图片**——前者不是线，后者不可编辑。
9. 导出测试直接断言 slide XML 里有 `<a:prstGeom prst="line">`、`<a:prstDash val="dash"/>` 和 `<a:tailEnd type="arrow"/>`，确保这些属性真的落到了文件里，而不是只留在画布上。

### 复制粘贴按组做

10. 新增 `duplicate-elements` 命令：一次复制一组，副本插在整组的最后面之后，保持原来的相对顺序。**一个命令、一个撤销项**。
11. `copyElementForPaste()` 抽出单条复制的逻辑给两个命令共用。文本副本的 `contentRef` 变成 `decorative`——标题和正文不能被复制成第二份，那会让一页出现两个标题。
12. 锁定的对象不参与复制。
13. 复制后选中这一组副本，用户能立刻看出复制出了什么。

### 适应窗口按容器实算

14. `src/core/rendering/viewport.ts` 的 `fitZoom()`：宽高两个方向都算，取较小值——只满足一个方向的话页面还是会被裁掉。留出固定边距。
15. 缩放**向下取整**到百分位。四舍五入会让页面刚好超出容器一点点，表现为底部被裁掉一条。
16. App 里用 `ResizeObserver` 监听画布容器的尺寸，容器变化时重新测量。容器的 padding 要从 `clientWidth`/`clientHeight` 里再扣一次，否则算出来的页面会盖住滚动条。
17. 缩放范围限制在 30%–300%，和界面上的加减按钮一致。

## 未覆盖与风险

- 线条只有水平、垂直、斜线三种方向，没有自由角度，也没有折线（多段线）。
- 没有弯曲的线条（贝塞尔曲线）。
- 适应窗口只按当前页面的尺寸算，页面比例改变后需要重新点一次。
- 复制粘贴只在当前页之间有效，跨页复制还没有做——剪贴板记的是对象 id，切换页面后 id 不在当前页时会提示"不在当前页面"。
- 复制粘贴用的是应用内部的剪贴板（记 id），不是系统剪贴板：不能把对象粘到别的应用里，也不能在关掉应用后还粘得上。
- 线条的可见性检查（过细的线是否看得见）没有做，导出报告里不提示。
