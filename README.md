# PPTD

PPTD 是一个以结构化文档模型为核心的桌面端 PPT 生成、设计与编辑平台。产品采用“内容生成与审核 → 视觉设计与导出”的两阶段工作流，目标是生成可继续编辑的 PPTX，而非整页图片。

当前仓库已经走出设计阶段：内容生成、内容审核、模板解析与套用、设计生成、视觉质检、2D 编辑和 PPTX 导出这条主链路已经可以跑通。需求以 [技术需求基线](docs/requirements/PPTD-TRS-v1.0.md) 为准，实施细节见：

- [系统架构](docs/architecture/system-architecture.md)
- [领域模型与版本规则](docs/architecture/domain-model.md)
- [V0.1 开发计划](docs/development/v0.1-plan.md)
- [工程约定与质量门禁](docs/development/engineering-guide.md)

## 核心约束

1. `Content Model` 与 `Design Model` 分离，设计操作不得静默修改已审核内容。
2. 编辑器、预览、导入和导出共享同一个 `PresentationDocument`。
3. 普通对象优先导出为 PowerPoint 原生可编辑对象。
4. PPTX 兼容能力按实际解析结果报告，不承诺任意文件无损往返。
5. V0.1 先完成 2D 编辑闭环，再扩展 OOXML、AI 与 3D 能力。

## 当前实现范围

- **内容工作台**：按主题、听众和重点生成结构化草稿，分大纲与正文批次产出，可查看逐页计划与可编辑内容块。
- **内容审核**：草稿先过结构化校验，再由用户确认；确认之前不改动当前文稿。确认后的内容会留下可追溯版本，编辑器内可逐页对比修改前后，并可只恢复内容（版式与对象保持当前状态）。
- **模板**：上传用户模板后提取母版、主题和页面版式，用于随后的设计生成与导出；模板库支持右键重命名与删除，分类/收藏仍未实现。
- **设计生成**：依据模板特征生成逐页版式、配色和页面层级，整册方向支持编辑式与纪实全幅（后者允许内容页主视觉、使用更窄的页边距且不画标题强调线）；无模板生成时会先给出这两个方向各 2 页真实预览，可选一个、跳过或换一组，选择记录随项目保存（可在设置中关闭该步骤）；视觉评审新增概念分，低于 60 时总分封顶 69；经过视觉质检后写入项目并进入编辑器，质检问题只作为报告，不阻断产出。
- **数据页关系**：数据页先判断占比、变化、构成、对比或量级，再选图表；趋势不会被画成饼图，占比不会被画成折线。没有关系信息时沿用旧的点数规则。
- **编辑器**：多页 2D 画布，文本、图片和 11 种预设形状（矩形、椭圆、三角形、菱形、五边形、六边形、V 形、箭头、星形、平行四边形、梯形），支持移动、缩放、旋转、层级、剪切/复制/粘贴与撤销重做，应用内剪贴板可跨页粘贴，支持在文本、表格、图表、备注和标题中查找/逐条或全部替换及当前页全选；“排列”功能区提供相对页面/相对所选对象的六向对齐、等距分布、90° 旋转和批量锁定，以及组合/取消组合（编辑期选择组，导出时展平为独立原生对象）；“插入”功能区可新建原生表格（2–12 列、1–50 数据行）与图表（柱状/条形/折线/饼图），插入即创建内容块并计入内容版本；文本可在“开始”功能区设置字体、字号、粗体/斜体/下划线/删除线、颜色、对齐、行距、项目符号/编号和缩进，格式刷可跨页套用，多选一次生效，导出仍是原生可编辑文本；“动画”功能区支持 9 种进入/强调/退出效果、计时、排序与复制，画布可预览；页面切换支持淡入淡出、推进、擦除和分割，可选速度与方向并导出为原生 transition；“设计”功能区可切换 16:9、4:3、16:10 或自定义页面尺寸（默认不缩放对象，可勾选“缩放对象”随页面等比缩放几何与字号）；原生表格的单元格和原生图表的指标可直接在属性面板中编辑，修改计入内容版本。
- **设计体检**：右侧属性面板提供确定性检查（正文字号、标签字号、标题/正文字阶比、字体与色彩数量、标题上方小标签、非序列编号、emoji、单字变色、连续同骨架、留白失衡），按硬底线与提示分级，只报告不阻断；可在设置中关闭，关闭后不显示面板、导出报告也不写体检字段。像素级问题仍由视觉评审负责。
- **评审证据**：视觉报告标明结论来自 PowerPoint 真实渲染、画布近似渲染还是仅确定性校验；证据跟随被采用的评审轮次，降级时不会冒充最终画面。
- **设计记忆**：本机保存最近项目的外观指纹（配色、字体、方向、页数）和方向选择时写下的偏好原话，下次方向提案时用于避免重复；不含正文、备注、图片，可在设置中关闭或一键清除。
- **资产来源**：图片可记录来源 URL、许可说明与核验状态；标记“已核验”要求两者齐全，命令按当前图片字节计算内容指纹；导出报告统计已核验、待核验、用户素材与未标注数量。
- **导入**：打开 PPTX 时先选“导入内容（Level A）”或“仅提取模板主题”；内容导入支持文本、图片、基础形状、基础表格、顶层与嵌套组合、单序列基础图表、主题色/字体和演讲备注，不支持对象逐项进入导入报告。
- **导出**：PptxGenJS 生成原生可编辑对象，导出前做字体、坐标和溢出预检；导出后独立回读包内文字与图片、表格、图表数量，结果写入结构化导出报告。

## 已知限制

- 视觉回归比对需要本机安装 PowerPoint 或 LibreOffice，用真实演示应用渲染导出的文件再逐像素比较。CI 环境不具备该工具链，用 `PPTD_SKIP_VISUAL=1` 跳过而不是假装通过；参考图按渲染器分别存放在 `tools/visual-regression/baseline/`。视觉评审开启后，首次生成会先用一张 64×64 测试图探测所选模型是否接受图片输入，结果按厂商和模型缓存在当前会话。
- 提示词回归套件（`npm run test:prompts`）用录制输出锁住方向、评审、设计合同与数据关系，不调用真实模型；它不评价真实模型的措辞质量、方向差异或概念分是否公允，这些仍需抽样与人工评审。
- LibreOffice 只能栅格化第一页，因此它只作为兜底渲染器，无法覆盖多页比对。
- 设计体检是确定性检查，只覆盖文本与对象级可判定项：模板底图内的装饰、图片内文字、抗锯齿与渲染器差异不在范围内，由视觉评审或人工确认。体检结果不持久化，重新打开项目时按当前文档重算。
- 设计方向门只用于无模板生成；上传模板已决定版式，沿用单方向路径。方向预览是代表性页面（封面 + 一页正文），单页环境下的模板版式轮换可能与最终整册不同。
- 导出回读只比对文字与原生对象数量，不覆盖图表标签（chart part）、演讲备注（notes part）与视觉布局；“回读通过”不代表视觉保真。
- 设计记忆仅保存在本机 SQLite，不跨设备；浏览器预览模式没有数据库，记忆不生效，也不回退到 localStorage。
- 图片来源需要用户手工填写；导入 PPTX 的图片与未标注的 AI 生成图都显示“未标注”。内容指纹用于检测图片是否被替换，不是密码学签名或版权凭证。
- 视觉评审的真实渲染目前依赖 Windows 与本机 PowerPoint；macOS/Linux 上报告为画布近似渲染，未接入 LibreOffice。
- 数据页关系只在生成时使用，不写进文档；属性面板不显示，评审也没有单独的关系匹配分。当前原生图表只有柱状、条形、折线、饼图，没有 100% 堆叠。
- AI 生成目前只登记了 MiniMax 一家厂商，需要用户在设置中自备 API Key；密钥不进入源码、项目文件和日志。
- 内容版本同时保存确认时刻的设计快照，可只恢复内容或显式“同时恢复版式”；恢复仍要求页面集合与块结构兼容，删除过页面或换过块结构时只能查看差异。视觉评审的总分、问题数和逐页评分会随项目保存（不含页面图片和模型原始响应）。
- 已支持 PPTX Level A 内容导入：页面尺寸与顺序、文字、图片、基础形状与常见预设形状、基础表格、顶层及嵌套组合、单序列基础图表、主题色/字体和演讲备注可进入编辑器；多序列图表只取第一个序列，SmartArt、媒体和动画会被跳过，未覆盖的复杂预设形状、跨表头/表体边界的合并和超过 12 列/50 行的表格会降级或截断，全部逐项写入导入报告。母版/版式不做视觉重建，Level B/C 与“智能重排/重新设计”未完整实现；导入内容为待审核状态，需另存为新的 `.pptd`。PPTX 仍由 PptxGenJS 重新生成，不是无损往返。
- 母版/版式保真、字体库、3D 场景和原生分组导出均未实现。九种对象动画会写成原生 `<p:timing>`（脉冲在 PowerPoint 中显示为 Grow/Shrink），页面切换写成原生 transition；图表动画因没有可寻址对象名而跳过并报告。分组是编辑期选择组，导出后成员是独立原生对象，导出报告会逐页提示。
- 表格/图表插入后不能增删行列或图表序列，导入的合并单元格只能编辑左上角内容、不能手工合并/拆分；修改页面尺寸默认不缩放对象，需勾选“缩放对象”；查找替换覆盖文本元素、表格单元格、图表标签/数值、演讲备注和文档标题，替换文本时会清除局部强调。
- 剪贴板是应用内剪贴板，不与系统或其他应用互通，切换项目会清空；组合整体缩放/旋转、嵌套组、组随复制粘贴保留均未实现；幻灯片浏览、放映和演讲者视图未实现。
